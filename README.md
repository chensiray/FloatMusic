# 浮音 FloatMusic

**让音乐留在手边。** 浮音是一款 Windows / Android 悬浮音乐播放器。平时收为可拖动的音符图标，点击后展开音乐卡片，在使用其他应用时也能控制播放、查看歌词和切换歌曲。

当前版本：**0.9 · 双端预览**。Windows 为 `0.9.0-preview.2`，Android 为 `0.9.0-preview`（版本码 12）。[下载 0.9 预览版](https://github.com/chensiray/FloatMusic/releases/tag/v0.9.0-preview)。

0.9 双端歌曲搜索可多选网易云、QQ 音乐、酷我音乐；不同平台的歌曲和本地音乐可放入同一个歌单，保留各自来源用于播放、歌词和现场恢复。QQ 与酷我目前使用普通音质。电脑端同步手机已有的歌词设置：显示方式和 14–26 号字号均在设置中，重启保留。具体入口见 [双端 0.9 验收说明](docs/双端-0.9-验收说明.md)。

## 主要功能

- **本地音乐**：导入 MP3、WAV、FLAC、OGG、M4A、AAC，单首不超过 30 MiB。Windows 还支持把文件拖入窗口或图标。
- **在线搜索**：双端可多选网易云、QQ 音乐、酷我音乐，搜索结果标明来源并保存曲库选择；单库失败时保留其他库的结果。在线歌单搜索目前为网易云，显示简介、作者与歌曲数量；默认无需配置 API 地址。
- **音乐排行榜**：查看热歌榜、新歌榜等服务提供的榜单，浏览歌曲、试听或整单导入本地歌单。
- **备用音源**：网易云内置播放优先使用 GD 音乐台，地址、连接或解码失败时尝试其他来源；设置中显示实际来源与音频格式。
- **播放控制**：播放、暂停、拖动进度、上一首、下一首、音量及音频输出选择；支持顺序、列表循环、单曲循环和随机播放，重启恢复歌曲与进度，默认暂停。
- **歌词**：在设置中选择原文、译文或双语，并调整 14–26 号字号；时间轴歌词自动高亮当前句并略微放大，手动翻看后可通过箭头返回。支持每首歌独立的时间微调。
- **歌单与收藏**：管理本地歌单和内置收藏夹，编辑简介、拖动排序，多选移动 / 复制 / 删除，导入导出 JSON；双端支持三个在线平台与本地歌曲混合存放。
- **外观**：浅色、深色、跟随系统；悬浮卡片支持拖动、整体等比缩放和背景不透明度调节。

## 获取与运行

本仓库提供源码。**Code → Download ZIP 下载的是源码，不能直接安装。** 安装包见 [0.9 Release](https://github.com/chensiray/FloatMusic/releases/tag/v0.9.0-preview)：

| 平台 | 下载 | 使用方式 |
|---|---|---|
| Windows x64 | [完整运行包 ZIP](https://github.com/chensiray/FloatMusic/releases/download/v0.9.0-preview/FloatMusic-0.9.0-preview.2-windows-x64.zip) | 解压完整目录后运行 `FloatMusic.exe`，保留全部 DLL 和插件 |
| Android ARM64 | [安装包 APK](https://github.com/chensiray/FloatMusic/releases/download/v0.9.0-preview/FloatMusic-0.9.0-preview-android-arm64.apk) | Android 9 及以上，同签名旧版可覆盖安装 |
| 文件校验 | [SHA256SUMS.txt](https://github.com/chensiray/FloatMusic/releases/download/v0.9.0-preview/SHA256SUMS.txt) | 核对下载文件的 SHA256 |

其他版本见 [Releases](https://github.com/chensiray/FloatMusic/releases)；自行编译见[构建说明](docs/DEVELOPMENT.md)。

主要使用环境为 Windows 11 x64 和 Android ARM64。Android 最低支持 Android 9；其他系统版本、设备及音频编码的兼容性可能不同。

### Windows

1. 解压完整运行包，运行 `FloatMusic.exe`。不要单独移动 EXE，需保留同目录的 DLL 和插件。
2. 点击蓝色音符图标，展开音乐卡片。
3. 点击 **更多 → 导入音乐**，或 **更多 → 搜索音乐**，选择想听的歌曲。

Windows 重复启动会唤起已有窗口；图标和卡片都可以接收拖入的单个音频文件。

升级前先从 **更多 → 退出浮音** 退出旧版，再启动新版，避免单实例机制继续唤起旧进程。歌单、收藏和设置保存在应用数据目录，替换运行目录不会自动删除这些数据。

### Android

1. 安装 ARM64 APK，打开浮音，在欢迎页点击 **显示悬浮窗**。
2. 按系统提示允许“显示在其他应用上方”，返回后使用音符图标。允许媒体通知后，可从通知栏控制播放。
3. 点击图标展开卡片，通过 **更多 → 导入音乐** 或 **更多 → 搜索** 开始使用。

返回欢迎页时，已有悬浮层会隐藏；离开后恢复。收起卡片或切换应用可继续播放，后台持续时间可能受手机省电策略影响。

本次 APK 使用调试签名，已对此前预览版完成保留数据的覆盖安装。若系统提示签名不一致，请先备份歌单并确认安装包来源，不要直接卸载旧版。

## 音乐卡片怎么用

上方始终保留歌名、歌手、进度、上下首、播放暂停和音量。拖动卡片顶部移动窗口；右上角 **减号** 将卡片收回图标。

| 入口 | 用途 |
|---|---|
| 歌词 | 查看逐句歌词、返回当前句、微调时间或重新获取；两端的原文/译文选择与字号均位于设置 |
| 歌单 | 选择歌单、查看简介与数量，通过操作面板管理歌单、排序、多选和导入导出 |
| 更多 → 搜索音乐（手机为“搜索”） | 切换歌曲 / 歌单搜索；在线歌单可打开详情、试听或整单导入 |
| 更多 → 排行榜 | 获取热歌榜等在线榜单，查看详情、试听、导入或刷新 |
| 更多 → 收藏当前 / 我的收藏（手机为“收藏”） | 收藏当前歌曲；收藏夹与其他歌单共用排序和批量管理功能 |
| 更多 → 设置 | 切换主题、大小、背景不透明度、音质、输出设备和音乐服务 |
| 更多 → 退出浮音 | 停止播放、移除悬浮窗并退出应用 |

**歌词、歌单、更多共用同一个下方区域**：点另一个按钮切换，再次点击当前按钮收起。列表或内容较长时，在区域内滚动。

歌单和搜索页的顶部工具随内容一起滚动，向下浏览时为歌曲留出更多空间；滚回顶部即可切换、管理歌单或重新搜索。Windows 的 `Ctrl+F` 可直接回到搜索框。

两端搜索框上方可勾选一个或多个曲库，默认全选。切换曲库后重新搜索；全部取消时会提示至少选择一项。歌曲行和当前播放信息显示来源，同名歌曲不会跨平台合并。切换到“歌单”后仍搜索网易云歌单。

导入本地音乐后需点击播放；试听搜索结果不会自动加入歌单。下一首右侧可选择播放模式；顺序模式自然播放到歌单末尾停止，循环和随机模式继续切歌。收藏和歌单均保存在本机，不会同步到网易云账号。

## 歌单导入与整理

在歌单页打开管理面板，可新建、改名、编辑简介、复制整单、导入或导出。收藏夹是内置歌单，旧收藏会自动迁入，名称固定且不能整单删除；移除收藏不会删除其他歌单中的同一曲目。

| 想做的事 | 操作方式 |
|---|---|
| 调整顺序 | Windows 拖动歌曲右侧手柄；Android 长按手柄后拖动，也可使用上下移操作 |
| 批量整理 | 进入多选，勾选歌曲后移动、复制、移除或导出；移动与复制保留原顺序，并合并目标歌单中的重复歌曲 |
| 导入在线歌单 | 在搜索中切换到“歌单”，打开详情后选择导入目标 |
| 传递歌单 | 从管理面板导出 JSON 文件或复制到剪贴板，再在另一端导入；也可只导出选中歌曲 |

文件格式为浮音 **UTF-8 JSON**，包含歌单名称、简介和曲目列表；单次导入、导出均最多 10000 首、8 MiB。Windows 保存时默认填入“歌单名称.json”。导入时可选择当前歌单、收藏夹或新歌单。

剪贴板还支持网易云完整歌单链接（`music.163.com/playlist?id=…`）或歌单数字 ID；短链接需先在浏览器打开并复制完整链接。在线歌单单次最多读取 2000 首，接口也可能只返回部分歌曲，详情页会提示实际可用数量。

**JSON 不包含音频文件。** 在线曲目可在另一台设备导入，播放仍依赖在线服务；本地曲目只记录文件位置，在目标设备不可访问时会被跳过并提示。导出歌单不会下载歌曲，也不能替代本地音频备份。

0.9 导出继续使用 JSON version 1，保留每首在线歌曲的平台和原始编号，不保存临时播放地址，兼容旧网易云歌单。两端 0.9 可互相传递混合歌单；Android 0.8 等旧版本会跳过 QQ、酷我曲目并提示，导入前请确认版本。

## 排行榜

在 **更多 → 排行榜** 首次打开时自动读取榜单。热歌榜、新歌榜、飙升榜和原创榜优先显示，其他榜单按服务返回顺序排列。点击进入详情后，可试听、加入当前歌单或选择整单导入目标；返回回到榜单列表。

榜单名称、简介、更新频率和数量以服务返回内容为准。可点击刷新重新获取；失败时显示原因并提供重试。榜单详情与在线歌单共用读取上限和不完整提示，不保证所有榜单、歌曲或音源始终可用。

## 音质、输出与外观

在 **更多 → 设置** 中调整：

- **音质**：网易云提供标准、较高、极高、无损、Hi-Res 五档。切换时尽量保留播放进度和暂停状态；实际格式取决于返回的音源，选择 Hi-Res 不保证文件达到该规格。QQ、酷我歌曲固定使用普通音质，切回网易云后恢复原先选定档位。
- **音频输出**：跟随系统默认，或选择列出的设备。连接蓝牙耳机后若无声，先确认系统已连接，再刷新输出列表并选择耳机。Android 的输出路由还受系统和设备支持情况限制。
- **大小**：Windows 为 90–140%，Android 为 90–130%，实际大小受屏幕可用空间限制。Windows 也可拖动卡片右下角等比缩放。
- **背景不透明度**：20–100%，只影响背景，文字和操作控件保持可见。
- **界面动效**：控制按钮按压与释放时的轻量反馈，可关闭；Android 同时遵循系统动画开关。
- **歌词显示与字号**：选择原文、译文或双语，字号范围 14–26，默认 18，当前句增加 2 号；设置中提供预览，两项均重启保留。

更多平台操作见 [Windows 使用指南](docs/Windows使用指南.md)和 [Android 使用指南](docs/Android使用指南.md)。

## 音乐服务与本地数据

网易云搜索、榜单和歌词使用站点接口；内置播放依次尝试 [GD 音乐台（GD Studio）](https://music.gdstudio.xyz/)、原第三方接口和 [INJAHOW Meting](https://api.injahow.cn/meting/)。0.9 的 QQ 搜索与普通音质解析使用 [落月 API](https://api.vkeys.cn/)，INJAHOW 提供备用；酷我搜索、解析和歌词使用 [Ourcraft 聚合接口](https://music.yuncan.xyz/api)。酷我优先使用接口明确返回的原始音频地址，连接或解码失败时尝试代理地址。每个平台保留自己的歌曲编号，换源不会自动替换成另一平台的同名歌曲。浮音不提供账号登录或云端歌单同步。

地址解析、音频连接和加载失败时自动尝试备用；单次解析有总超时，暂时故障的接口冷却 30 秒，GD 请求还受本机频率保护。设置显示来源、请求档位及实际播放格式；INJAHOW 在实测中提供 MP3 128 kbps，备用来源不保证无损或 Hi-Res。接口仍可能同时超时、限流或缺少部分歌曲；网易云可重试或更换音质，QQ、酷我可重试或尝试其他歌曲。

拥有网易云兼容服务时，可在 **更多 → 设置 → 音乐服务** 填写地址；该地址仅影响网易云，网易云自定义模式只访问所选服务，恢复内置后重新启用备用来源。勾选的 QQ、酷我仍访问各自内置服务。Windows 的接口请求遵循系统代理配置，Android 遵循设备网络环境。网络与实验边界见[验证说明](VERIFICATION.md)，历史备用音源参数见[实测记录](docs/备用音源接入与实测-2026-10-01.md)。

GD 音乐台 API 由 GD Studio 提供，按其公开规则仅用于个人学习和非商业用途，并保留来源说明；浮音不提供在线歌曲下载或分发。

本地导入会在应用数据目录保存音频副本，原文件不修改，音频不会上传。歌单、收藏和设置保存在本机；移除曲目或删除歌单不会删除原文件，导入副本目前也不会自动清理。搜索词、歌曲编号等在线请求会发送给对应服务。

## 当前限制与反馈

歌单支持 JSON 批量导入和拖动排序；目前不支持批量导入音频文件、本地 LRC 导入及在线歌曲下载。不同手机的省电策略、屏幕尺寸和蓝牙设备仍需持续适配。

0.9 已完成桌面七组离线回归、Android 解析与状态回归、手机原生控件和列表滑动检查；真实三曲库歌曲在手机上的逐项播放、后台场景及不同设备适配仍需扩大覆盖。具体自动检查、安装状态、实测条件与限制见[验证说明](VERIFICATION.md)。第三方接口可能超时、限流或缺少歌曲，有限样本通过不代表所有曲目始终可播；酷狗尚未取得可播证据，本版未接入。

遇到问题可提交 [Issue](https://github.com/chensiray/FloatMusic/issues)，请附上应用版本、系统/设备型号、复现步骤与实际表现。
