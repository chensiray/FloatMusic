# 浮音 FloatMusic

[简体中文](README.md) | [English](README_en.md)

**让音乐留在手边。** 浮音是一款 Windows / Android 悬浮音乐播放器。平时收为可拖动的音符图标，点击后展开音乐卡片，在使用其他应用时也能控制播放、查看歌词和切换歌曲。

当前版本：**1.2 · 双端预览**。Windows / Android 均为 `1.2.0-preview`，Android 版本码 16。源码与安装包见 [1.2 Release](https://github.com/chensiray/FloatMusic/releases/tag/v1.2.0-preview)。

1.2 新增独立播放队列、最近播放和睡眠定时。歌曲可以安排为下一首或加入队尾，队列支持重复曲目、拖动排序、移除、清空与重启恢复。Windows 增加可修改的全局快捷键，Android 通知栏补齐播放、进度、模式和音量控制。混合歌单、独立音质、歌词字号与行距等原有功能继续保留。入口见 [Windows 1.2 验收说明](docs/Windows-1.2-验收说明.md) 和 [Android 1.2 验收说明](docs/Android-1.2-验收说明.md)。

## 主要功能

- **本地音乐**：导入 MP3、WAV、FLAC、OGG、M4A、AAC，单首不超过 30 MiB。Windows 还支持把文件拖入窗口或图标。
- **在线搜索**：歌曲与歌单均可多选网易云、QQ 音乐、酷我音乐，结果标明来源并保存曲库选择；单库失败时保留其他库结果。设置可调整合计显示上限，结果轮流取自所选曲库；没有足够匹配项时按实际数量显示。
- **音乐排行榜**：切换三个平台，浏览歌曲、试听或整单导入本地歌单。QQ 动态读取榜单目录；酷我提供已验证的热歌、新歌、飙升三个榜单，歌曲实时读取。
- **备用音源**：网易云内置播放优先使用 GD 音乐台，地址、连接或解码失败时尝试其他来源；设置中显示实际来源与音频格式。
- **独立音质**：网易云提供标准至 Hi-Res，QQ 提供标准 / 320 / FLAC / 实验母带，酷我提供标准 / 320 / FLAC；三个偏好独立保存，缺档时尝试同曲较低档，展示实际音频规格。
- **播放控制**：播放、暂停、拖动进度、上一首、下一首、音量及音频输出选择；音量按钮向上展开竖直滑条。支持顺序、列表循环、单曲循环和随机播放，重启恢复歌曲与进度，默认暂停。
- **播放队列**：单首下一首 / 队尾、独立重复项、拖动排序、移除与清空，保存顺序和当前项，重启默认暂停。
- **最近播放**：记录实际开始播放的歌曲，最多 200 首，支持重播、加入队列或歌单及清空。
- **睡眠定时**：15 / 30 / 60 分钟、自定义 1–180 分钟或播完当前曲停止，支持取消，重启关闭。
- **快捷键与通知**：Windows 全局快捷键可在设置中修改；Android 提供系统媒体通知与控制。
- **歌词**：在设置中选择原文、译文或双语，调整 10–30 号字号与 0.8–3.0 倍行距，实时预览并保存；时间轴歌词自动高亮当前句并略微放大，手动翻看后可通过箭头返回。支持每首歌独立的时间微调。
- **歌单与收藏**：管理本地歌单和内置收藏夹，编辑简介、拖动排序，多选移动 / 复制 / 删除，导入导出 JSON；双端支持三个在线平台与本地歌曲混合存放。
- **外观**：浅色、深色、跟随系统；悬浮卡片支持拖动、整体等比缩放和背景不透明度调节。

## 获取与运行

本仓库提供源码。**Code → Download ZIP 下载的是源码，不能直接安装。** 请从 [1.2 Release](https://github.com/chensiray/FloatMusic/releases/tag/v1.2.0-preview) 下载对应平台的运行包：

| 平台 | 下载 | 使用方式 |
|---|---|---|
| Windows x64 | [完整运行包 ZIP](https://github.com/chensiray/FloatMusic/releases/download/v1.2.0-preview/FloatMusic-1.2.0-preview-windows-x64.zip) | 解压完整目录后运行 `FloatMusic.exe`，保留全部 DLL 和插件 |
| Android ARM64 | [安装包 APK](https://github.com/chensiray/FloatMusic/releases/download/v1.2.0-preview/FloatMusic-1.2.0-preview-android-arm64-v8a.apk) | Android 9 及以上，同签名旧版可覆盖安装 |
| 文件校验 | [SHA256SUMS.txt](https://github.com/chensiray/FloatMusic/releases/download/v1.2.0-preview/SHA256SUMS.txt) | 核对下载文件的 SHA256 |

其他版本见 [Releases](https://github.com/chensiray/FloatMusic/releases)；自行编译见[构建说明](docs/DEVELOPMENT.md)。

主要使用环境为 Windows 11 x64 和 Android ARM64。Android 最低支持 Android 9；其他系统版本、设备及音频编码的兼容性可能不同。

### Windows

1. 解压完整运行包，运行 `FloatMusic.exe`。不要单独移动 EXE，需保留同目录的 DLL 和插件。
2. 点击蓝色音符图标，展开音乐卡片。
3. 点击 **更多 → 导入音乐**，或 **更多 → 搜索音乐**，选择想听的歌曲。

Windows 重复启动会唤起已有窗口；图标和卡片都可以接收拖入的单个音频文件。

升级前先从 **更多 → 退出浮音** 退出旧版，再启动新版，避免单实例机制继续唤起旧进程。歌单、收藏和设置保存在应用数据目录，替换运行目录不会自动删除这些数据。

### Android

1. 安装 ARM64 APK，打开浮音，在欢迎页点击 **显示悬浮窗**。
2. 按系统提示允许“显示在其他应用上方”，返回后使用音符图标。允许媒体通知后，可从通知栏控制播放。
3. 点击图标展开卡片，通过 **更多 → 导入音乐** 或 **更多 → 搜索音乐** 开始使用。

返回欢迎页时，已有悬浮层会隐藏；离开后恢复。收起卡片或切换应用可继续播放，后台持续时间可能受手机省电策略影响。

预览 APK 使用调试签名；1.2 包的签名已确认与 1.1 相同，本次真机安装状态见[验证说明](VERIFICATION.md)。若系统提示签名不一致，请先备份歌单并确认安装包来源，不要直接卸载旧版。

## 音乐卡片怎么用

上方始终保留歌名、歌手、进度、上下首、播放暂停和音量。拖动卡片顶部移动窗口；右上角 **减号** 将卡片收回图标。

音量按钮与上一首、播放/暂停、下一首和模式并列，点击后向上弹出竖直滑条；向上拖动增加音量，向下减少，点击外侧或按返回 / Esc 收起。

| 入口 | 用途 |
|---|---|
| 歌词 | 查看逐句歌词、返回当前句、微调时间或重新获取；两端的原文/译文选择、字号和行距均位于设置 |
| 歌单 | 选择歌单、查看简介与数量，通过操作面板管理歌单、排序、多选和导入导出 |
| 更多 → 搜索音乐 | 切换歌曲 / 歌单搜索；在线歌单可打开详情、试听或整单导入 |
| 更多 → 播放队列 | 查看本次播放顺序、拖动排序、播放、移除或清空 |
| 更多 → 最近播放 | 重播最近听过的歌曲、加入队列或歌单、清空记录 |
| 更多 → 睡眠定时 | 设置倒计时或播完当前曲停止，查看状态及取消 |
| 更多 → 排行榜 | 获取热歌榜等在线榜单，查看详情、试听、导入或刷新 |
| 更多 → 收藏当前 / 我的收藏（手机为“收藏歌单”） | 收藏当前歌曲；收藏夹与其他歌单共用排序和批量管理功能 |
| 更多 → 设置 | 按播放音质、歌词、外观、搜索与服务分组，调整独立音质、字号、行距、输出设备等 |
| 更多 → 退出浮音 | 停止播放、移除悬浮窗并退出应用 |

**歌词、歌单、更多共用同一个下方区域**：点另一个按钮切换，再次点击当前按钮收起。列表或内容较长时，在区域内滚动。

歌单和搜索页的顶部工具随内容一起滚动，向下浏览时为歌曲留出更多空间；滚回顶部即可切换、管理歌单或重新搜索。Windows 的 `Ctrl+F` 可直接回到搜索框。

两端搜索框上方可勾选一个或多个曲库，默认全选，歌曲与歌单共用选择。切换曲库后重新搜索；全部取消时会提示至少选择一项。结果和当前播放信息显示来源，同名歌曲不会跨平台合并。在 **更多 → 设置 → 搜索显示数量** 选择合计上限，歌曲与歌单共用，修改从下次搜索生效，重启保留。

导入本地音乐后需点击播放；试听搜索结果不会自动加入歌单。下一首右侧可选择播放模式；顺序模式自然播放到歌单末尾停止，循环和随机模式继续切歌。收藏和歌单均保存在本机，不会同步到网易云账号。

## 播放队列、历史与睡眠定时

在歌曲操作菜单选择“下一首播放”或“加入队尾”，不会打断当前歌曲；指定下一首优先于循环或随机模式。同曲可重复添加，每次添加都能独立排序和移除。歌单页点击歌曲会按该歌单建立队列，成功准备音乐后才替换原队列；仅切换或整理保存的歌单不会改变队列。

队列最多 10000 项，可拖动排序，也可通过菜单移动；移除当前项后本首继续，清空后曲终停止。顺序、当前项与进度会恢复，重启默认暂停。播放队列与保存的歌单分别管理，清空队列不会删除歌单。

最近播放最多保存 200 首实际开始播放的歌曲，同曲重播移到最前；加载失败或仅加入队列不产生历史，支持重播、加入队列或歌单与清空。暂停继续及同次播放的音质重载不重复记录；重启后主动继续听歌会记录本次播放。

睡眠定时提供 15 / 30 / 60 分钟、自定义 1–180 分钟和“播完当前歌曲停止”。倒计时在暂停和后台期间继续，到期后阻止迟到的加载请求或焦点恢复自动播放；可取消，重启关闭。

## 快捷键与手机媒体通知

Windows 在“更多 → 设置 → 全局快捷键”中查看或修改组合，支持禁用与恢复默认，冲突时保留原配置。默认 `Ctrl+Alt+Space` 播放/暂停，`Ctrl+Alt+Left / Right` 上下首，`Ctrl+Alt+Up / Down` 调整音量，`Ctrl+Alt+M` 展开/收起；其他程序在前台时也可使用。原有 `Ctrl+F`、`Ctrl+O` 和 `Esc` 仍在播放器窗口内使用。

Android 媒体通知显示歌曲、歌手、进度和时长，支持上下首、播放/暂停、播放模式和音量；系统提供进度条时可拖动定位。音量按钮打开悬浮卡片的竖直滑条，收起通知面板后调整；从欢迎页操作会回到悬浮卡片，文件选择期间等待选择结束。控件顺序、折叠方式和锁屏显示由手机系统决定，仍需允许通知与悬浮权限。

## 歌单导入与整理

在歌单页打开管理面板，可新建、改名、编辑简介、复制整单、导入或导出。收藏夹是内置歌单，旧收藏会自动迁入，名称固定且不能整单删除；移除收藏不会删除其他歌单中的同一曲目。

| 想做的事 | 操作方式 |
|---|---|
| 调整顺序 | Windows 拖动歌曲右侧手柄；Android 长按手柄后拖动，也可使用上下移操作 |
| 批量整理 | 进入多选，勾选歌曲后移动、复制、移除或导出；移动与复制保留原顺序，并合并目标歌单中的重复歌曲 |
| 导入在线歌单 | 在搜索中切换到“歌单”，打开详情后选择导入目标 |
| 传递歌单 | 从管理面板导出 JSON 文件或复制到剪贴板，再在另一端导入；也可只导出选中歌曲 |

文件格式为浮音 **UTF-8 JSON**，包含歌单名称、简介和曲目列表；单次导入、导出均最多 10000 首、8 MiB。Windows 保存时默认填入“歌单名称.json”。导入时可选择当前歌单、收藏夹或新歌单。

剪贴板支持网易云、QQ、酷我完整歌单链接，例如 `music.163.com/playlist?id=…`、`y.qq.com/n/ryqq/playlist/…`、`www.kuwo.cn/playlist_detail/…`。裸数字 ID 仍按网易云读取；短链接需先在浏览器打开并复制完整链接。在线歌单单次最多读取 2000 首，接口也可能只返回部分歌曲，详情页会提示已读取数量和不完整原因。

**JSON 不包含音频文件。** 在线曲目可在另一台设备导入，播放仍依赖在线服务；本地曲目只记录文件位置，在目标设备不可访问时会被跳过并提示。导出歌单不会下载歌曲，也不能替代本地音频备份。

1.2 导出继续使用 JSON version 1，保留每首在线歌曲的平台和原始编号，不保存临时播放地址，兼容旧网易云歌单和 0.9 混合歌单。两端 0.9 / 1.0 / 1.1 / 1.2 可互相传递混合歌单；Android 0.8 等旧版本会跳过 QQ、酷我曲目并提示，导入前请确认版本。

## 排行榜

在 **更多 → 排行榜** 首次打开时自动读取榜单。热歌榜、新歌榜、飙升榜和原创榜优先显示，其他榜单按服务返回顺序排列。点击进入详情后，可试听、加入当前歌单或选择整单导入目标；返回回到榜单列表。

榜单名称、简介、更新频率和数量以服务返回内容为准。可点击刷新重新获取；失败时显示原因并提供重试。榜单详情与在线歌单共用读取上限和不完整提示，不保证所有榜单、歌曲或音源始终可用。

## 音质、输出与外观

在 **更多 → 设置** 中调整：

- **音质**：三个曲库各自保存。网易云提供标准、较高、极高、无损、Hi-Res；QQ 提供标准、高音质 320、无损 FLAC、实验母带；酷我提供标准、高音质 320、无损 FLAC。无歌曲或加载时也可设置；修改当前歌曲来源的档位会重新加载并保留进度与播放/暂停状态，修改其他来源不打断播放。高档不可用时尝试同曲较低档，实际格式和采样规格以返回音频为准，选择高档不保证每首都可用。
- **音频输出**：跟随系统默认，或选择列出的设备。连接蓝牙耳机后若无声，先确认系统已连接，再刷新输出列表并选择耳机。Android 的输出路由还受系统和设备支持情况限制。
- **大小**：Windows 为 90–140%，Android 为 90–130%，实际大小受屏幕可用空间限制。Windows 也可拖动卡片右下角等比缩放。
- **背景不透明度**：20–100%，只影响背景，文字和操作控件保持可见。
- **界面动效**：控制按钮按压与释放时的轻量反馈，可关闭；Android 同时遵循系统动画开关。
- **歌词显示、字号与行距**：选择原文、译文或双语，字号范围 10–30，默认 18，当前句增加 2 号；行距范围 0.8–3.0 倍、步进 0.1，默认 1 倍自然行高，字号缩小时行距随之缩小。两行预览实时更新，逐句与纯文本均生效，调节时保持手动翻看位置，退出重启后保留。

音质和输出设备位于播放设置，歌词选项集中在歌词分组；自定义网易云服务地址默认折叠。QQ 实验母带只在选择该档时请求，可能增加加载时间；较高采样规格不证明原始母带品质。接口样本见[高音质调研](docs/QQ音乐与酷我音乐高音质接口调研-2026-10-06.md)。

更多平台操作见 [Windows 使用指南](docs/Windows使用指南.md)和 [Android 使用指南](docs/Android使用指南.md)。

## 音乐服务与本地数据

网易云搜索、榜单和歌词使用站点接口；内置播放依次尝试 [GD 音乐台（GD Studio）](https://music.gdstudio.xyz/)、原第三方接口和 [INJAHOW Meting](https://api.injahow.cn/meting/)。QQ 歌曲搜索与音质解析使用 [落月 API](https://api.vkeys.cn/)，INJAHOW 提供普通音质备用；酷我歌曲搜索和歌词使用 [Ourcraft 聚合接口](https://music.yuncan.xyz/api)，播放优先通过公开 mobi 接口请求对应音质，再尝试聚合接口的原始地址与代理备用。每个平台保留自己的歌曲编号，换源不会自动替换成另一平台的同名歌曲。浮音不提供账号登录或云端歌单同步。

QQ 歌单搜索、详情和榜单使用匿名 musicu 接口；酷我歌单使用搜索与歌单服务，榜单详情使用公开客户端协议。接口说明与候选选择见[歌单与排行榜调研](docs/QQ音乐与酷我音乐歌单排行榜接口调研-2026-10-05.md)。这些接口读取公开信息，播放仍取决于音源可用性；没有加入账号登录或付费内容解锁。

地址解析、音频连接和加载失败时自动尝试备用；单次解析有总超时，暂时故障的接口冷却 30 秒，GD 请求还受本机频率保护。设置显示来源、请求档位及实际播放格式；INJAHOW 在实测中提供 MP3 128 kbps，备用来源不保证无损或 Hi-Res。高音质响应会检查曲目身份和音频格式，酷我还结合目标时长拒绝明显不完整或无法确认完整性的短音频。接口仍可能同时超时、限流或缺少部分歌曲，可重试、更换音质或尝试其他歌曲。

拥有网易云兼容服务时，可在 **更多 → 设置 → 音乐服务** 填写地址；该地址仅影响网易云，网易云自定义模式只访问所选服务，恢复内置后重新启用备用来源。勾选的 QQ、酷我仍访问各自内置服务。Windows 的接口请求遵循系统代理配置，Android 遵循设备网络环境。网络与实验边界见[验证说明](VERIFICATION.md)，历史备用音源参数见[实测记录](docs/备用音源接入与实测-2026-10-01.md)。

GD 音乐台 API 由 GD Studio 提供，按其公开规则仅用于个人学习和非商业用途，并保留来源说明；浮音不提供在线歌曲下载或分发。

本地导入会在应用数据目录保存音频副本，原文件不修改，音频不会上传。歌单、收藏和设置保存在本机；移除曲目或删除歌单不会删除原文件，导入副本目前也不会自动清理。搜索词、歌曲编号等在线请求会发送给对应服务。

## 当前限制与反馈

歌单支持 JSON 批量导入和拖动排序；目前不支持批量导入音频文件、本地 LRC 导入及在线歌曲下载。不同手机的省电策略、屏幕尺寸和蓝牙设备仍需持续适配。

1.2 的自动检查、匿名接口样本与手机安装状态见[验证说明](VERIFICATION.md)。第三方接口可能超时、限流或缺少歌曲，有限样本通过不代表所有曲目始终可播；酷狗尚未取得可播证据，本版未接入。不同设备适配和手机后台场景仍需扩大覆盖。

遇到问题可提交 [Issue](https://github.com/chensiray/FloatMusic/issues)，请附上应用版本、系统/设备型号、复现步骤与实际表现。
