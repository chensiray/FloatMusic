# 浮音 FloatMusic

**让音乐留在手边。** 浮音是一款支持 Windows 和 Android 的悬浮音乐播放器：用一个可拖动的小图标收起界面，需要时展开播放控制，在浏览网页、工作或使用其他应用时继续听歌。

当前版本：**0.4.0 · 预览版**。Android 悬浮窗仍有已知交互问题，见下方说明。

## 可以做什么

- **播放本地音乐**：导入 MP3、WAV、FLAC、OGG、M4A、AAC，单首不超过 30 MiB。Windows 支持将文件拖入窗口或悬浮图标。
- **按歌名搜索**：内置网易云音乐搜索，搜索结果可以直接试听，也可以加入本地歌单。
- **选择在线音质**：标准、较高、极高、无损、Hi-Res 五档；切换时尽量保留进度和暂停状态。实际音质取决于服务返回的音源。
- **查看歌词**：支持原文、译文及两者同时显示，可滚动阅读和重新获取。
- **管理本地歌单**：新建、重命名、删除歌单，添加或移除歌曲，支持上一首、下一首及顺序续播。
- **控制播放**：播放、暂停、拖动进度、调节音量、选择音频输出；Android 的具体输出路由由系统和设备支持情况决定。
- **切换外观**：浅色、深色、跟随系统。电脑使用侧栏，手机使用底部导航，播放控制保留在底部。

## 平台与悬浮方式

| | Windows | Android |
|---|---|---|
| 收起后 | 可拖动的桌面音符图标 | 其他应用上方的音符图标 |
| 点击图标 | 打开播放器主窗口 | 打开独立悬浮播放页面 |
| 导入文件 | 文件选择器或拖放 | 系统文件选择器 |
| 后台播放 | 收起窗口后继续播放 | 前台播放服务与媒体通知 |
| 退出 | 点击“退出”或关闭主窗口 | 点击主界面或悬浮页的“退出” |

Windows 重复启动会唤起已有窗口。Android 进入主界面时自动隐藏悬浮层，离开后恢复；首次开启需要授予“显示在其他应用上层”权限。普通后台播放不需要开启悬浮窗。

目前主要验证环境为 Windows 11 x64 与 Android ARM64 真机；Android 最低版本为 Android 9。其他设备的兼容性仍在完善。

## 安装与开始使用

本仓库提供源码。若 [Releases](https://github.com/chensiray/FloatMusic/releases) 中提供与你的平台对应的安装包，可从该页面下载；没有对应安装包时，请参考[构建说明](docs/DEVELOPMENT.md)。

**Windows**：解压完整程序包，运行 `FloatMusic.exe`。请保留同目录中的运行库和资源，不要只移动 EXE 文件。

**Android**：安装 ARM64 APK，打开“浮音”。需要悬浮播放时点击顶部“悬浮窗”，按系统提示授予权限后返回应用。需要时允许媒体通知，以便从通知栏控制播放。

1. 打开“本地”，点击“导入音乐”；或打开“搜索”，输入歌名查找在线音乐。
2. 点击歌曲的播放按钮。导入本地文件后不会自动播放；直接试听搜索结果不会自动加入歌单。
3. 用底部播放栏控制进度、音质和音量；点击“歌词”打开歌词页面。
4. 在“歌单”中管理收藏到本地歌单的曲目，在“设置”中切换外观或配置音乐服务。
5. 收起界面继续听歌；要完全停止播放，请使用“退出”。Android 键盘显示时按返回键先收起键盘，否则退到后台。

手动上一首、下一首会循环切换；自然播放到歌单末尾后停止。删除歌单或移除曲目不会删除原始音乐文件。

## 音乐服务与数据

默认无需填写 API 地址。搜索和歌词使用网易云站点接口，在线音频地址由第三方服务提供；浮音不是网易云音乐官方客户端，不提供账号登录或云端歌单同步。

外部服务可能超时、限流或缺少部分歌曲。出现错误时，界面会显示原因，可重试或更换音质。**选择 Hi-Res 不代表返回文件一定达到 Hi-Res 规格。** 有自己的兼容服务时，可在“设置 → 音乐服务”填写地址，留空或点击“恢复内置”可切回默认服务。

本地导入会在应用数据目录保存音频副本，原文件不修改，也不会上传；歌单和设置保存在本机。从歌单移除歌曲后，导入副本暂不自动清理。搜索词、歌曲编号等请求会发送给对应在线服务。

## 已知限制

0.4 预览版存在以下 Android 悬浮窗问题，已记录，计划后续修复：

- 悬浮窗下方存在多余空白占用区域，点击该区域没有反应。
- 不透明度调得较低时，悬浮窗可能无法响应点击或拖动。建议暂时保持较高不透明度。
- 大小滑块目前只调整宽度；后续计划支持宽高等比例缩放。

当前歌词不支持逐句滚动高亮；独立“收藏”功能尚未开放，可先使用本地歌单保存曲目。批量导入、歌曲排序、随机播放、单曲循环和下载功能尚未提供。不同手机的省电策略可能影响长时间后台播放。
