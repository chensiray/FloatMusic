# Android 1.1 fixture

`run-overlay-v11-contract-test.ps1` compiles all production Android Java, local Qt bindings, and the 1.1 / 1.0 / 0.9 UI fixtures with local API 36 and Java 8. It runs eleven native-overlay JVM contract groups without a device or network. The new checks cover independent per-source requests and legacy migration, popup bounds on normal/short layers, upward volume direction/clamping, and line-spacing preference normalization/defaults/proportional row advance.

`run-overlay-v11-ui-test.ps1 -DeviceSerial <serial> [-AdbPort 5038] [-Screenshots]` requires the rebuilt 1.1 target APK, its overlay permission, and the local Android debug key. It installs only a separate test package, runs eight actual-view scenes, captures results, then removes that package. The target app is retained. The default ADB server port is 5037; an explicit serial is always required.

The eight scenes verify native service dispatch/persistence for independent QQ master and Kuwo lossless, editable selectors while local/busy, pending snapshot acknowledgement and preserved API editing; volume icon/vertical drag/Back/outside dismissal; the popup bounds and drag region on a forced 180dp card; 10sp timed bilingual rows, wrapped long Chinese text and manual-scroll return; natural plain bilingual text height; the full 10–30sp persisted font range; the custom-service fold/draft/scroll behavior; and line spacing. The new `line-spacing` scene exercises 0.8/1.7/3.0 choices through the real slider and two-line preview, reloads persisted preferences, checks malformed/NaN settings, verifies single-line row advances, long wrapped/bilingual and plain text in every lyric mode, and preserves a manually viewed row while spacing changes. Both volume scenes draw the real slider at 0/50/100 after dragging and after external snapshots, checking the thumb bounds and pixels beside the thin track. These fixtures use separate preferences through an isolated context. They do not call live audio resolution or alter the user's music-service preferences.

Screenshots are saved in the target app cache folder `v11-ui-fixture`, including twelve small volume slider frames named `volume-popup` / `volume-short` with `drag` / `snapshot` and `0` / `50` / `100` suffixes. The 1.0 fixture remains the source/search/ranking/metadata and list-refresh regression suite. Its quality scene now expects three editable source selectors. `run-overlay-v1-ui-test.ps1` also accepts `-AdbPort`. The existing scroll fixture continues to cover large local playlists, song results and playlist-search gestures.

The native volume popup is measured in the unscaled popup layer and clamps all four edges. Its slider has a 48dp-wide drag region; normal upward placement shrinks to the room above the anchor, retaining at least an 88dp popup when a short card has limited room. At the 180dp test height the outer player can scroll to the controls. Lyrics use wrap-content glyph height, zero top/bottom or font padding, and a 0.8–3.0 multiplier in 0.1 steps, saved as `window/lyricLineSpacing`. The default is 1.0 with no row gap. Each timed row adds proportional leading after its final natural line; compact factors use a negative margin to overlap row steps while retaining complete glyph bounds. Missing/non-numeric/non-finite/out-of-range preferences return to 1.0. The current line remains two sp larger, and spacing changes preserve manual browsing instead of resuming following.
