# Windows 1.2 验收说明

本次为电脑端 `1.2.0-preview`，已获用户验收，用户已授权发布双端 1.2。先在“更多 → 退出浮音”退出旧版，再运行完整运行目录的 `FloatMusic.exe`。沿用已有歌单、音质、歌词及外观设置；手机端同步与通知栏增强已完成，见 [Android 1.2 验收说明](Android-1.2-验收说明.md)。

## 播放队列

从歌单、歌曲搜索或在线歌单的歌曲菜单选择“下一首播放”或“加入队尾”，然后打开“更多 → 播放队列”。检查混合曲库、同曲重复添加、指定下一首与随机 / 单曲循环的配合、当前项高亮、左侧手柄拖动及列表边缘自动滚动。

队列菜单提供现在播放、上移、下移、移除。移除和清空需要确认；删除当前项时本首继续，下一首从原位置接续；清空后本首结束停止。切换或整理保存歌单应保留当前队列；点击歌单歌曲才会按该歌单重新建立队列。加载失败时应保留实际播放歌曲及对应队列位置。

调整顺序后退出重启，检查顺序、重复项和当前歌曲恢复，默认暂停。已清空的队列保持为空；旧版播放现场可迁移。缺失的本地文件保留曲目信息，播放时给出提示。

## 最近播放与睡眠定时

“更多 → 最近播放”只记录实际开始播放的歌曲，同曲再次播放移到最前；暂停继续和音质重载不重复更新时间。最多 200 首，支持再次播放、下一首 / 队尾、确认清空；清空不会打断当前歌曲。

“更多 → 睡眠定时”提供 15 / 30 / 60 分钟、1–180 分钟自定义和播完当前歌曲。检查标题栏定时状态、取消及覆盖旧定时；到期暂停，迟到的音源请求也不会自动响起。播完本首应优先于循环模式，重启后定时关闭。

## 快捷键与适配

在设置的全局快捷键分组中检查默认组合、修改、重复冲突、被其他程序占用、禁用及恢复默认；详细组合见 [Windows 使用指南](Windows使用指南.md#退出与快捷键)。其他程序在前台时验证播放、上下首、音量和展开 / 收起。录入快捷键时不应触发播放控制，冲突应保留原配置。

检查浅色 / 深色、90% / 140% 缩放、较小工作区和长歌名。队列、历史及设置应可滚动到底，顶部工具随列表滚动；弹出框不应遮挡后无法操作。原有歌词翻译、10–30 号字体和 0.8–3.0 倍行距应继续工作。
