# 1.7.0-preview.3：歌词颜色进度

Windows 与 Android 的播放器歌词、独立悬浮歌词增加从左到右的颜色覆盖，默认开启。底色保持可读，沿用紫色高亮、原有字号、行距与透明度曲线。

在“设置 → 播放器歌词”或“设置 → 桌面歌词／独立悬浮歌词”关闭“歌词颜色进度”，即可恢复原有整句高亮。两处入口共用一个保存的开关，支持中英文。

普通逐句歌词使用当前句到下一句的时间区间匀速覆盖；最后一句使用歌曲总时长。歌词源没有逐字时间数据，因此不承诺与每个字的演唱精准对齐。无有效时间区间时保留整句高亮，纯文本歌词保持原样。

长句换行按各行实际文字宽度依次推进，双语原文和译文同步覆盖。暂停冻结，恢复、定位和歌词时间微调重新同步。独立悬浮歌词删除空行后，仍使用未压缩的原始时间戳作为句尾，避免把间奏算进前一句。

颜色动画复用现有文字布局与缓存位图，不重排列表或移动系统窗口；关闭效果、暂停、隐藏窗口、手动浏览使当前句离开屏幕或覆盖完成时停止额外帧刷新。移动端高亮底图在布局更新时准备，绘制帧只做裁剪与合成。

版本：1.7.0-preview.3；Android versionCode 33，ARM64，最低 Android 9。沿用原有签名，可覆盖安装之前的预览。
