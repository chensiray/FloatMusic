# Android 1.3 验收说明

本次将电脑端已选定的 07A 珠光视觉与深色优化同步到手机。应用版本为 `1.3.0-preview`，版本码 17，最低 Android API 28，目标 API 36。已在连接的 MTN-AN80 手机上保留数据覆盖安装，并打开欢迎页；当前为本地验收预览。

## 查看效果

打开浮音，点击“显示悬浮窗”，轻点音乐图标展开播放器。在“更多 → 设置”分别切换浅色与深色。

- 浅色：珠白阅读面、深靛文字、紫色播放键，左上青蓝与右下粉紫角雾，以及细玻璃光谱边缘。
- 深色：深靛阅读面、更清楚的青蓝／粉紫轮廓、浓紫渐变播放键与白色图标，选中项与弹层有独立明度层次。
- 歌词、歌单、设置及音量／管理弹层使用相同配色。欢迎页与收起后的音乐图标同步更新。

音乐卡片、控件位置、按钮尺寸、字号、抽屉与滚动结构均沿用手机端 1.2。原生按钮仍保持 48dp 触控区域，虹彩没有额外动画。

## 建议验收

1. 选择一首常听的歌，切换歌词、歌单与设置，查看边缘颜色与正文是否舒服。
2. 在浅色、深色分别展开音量与播放模式菜单，检查边缘、选中状态与文字清晰度。
3. 调整背景透明度，确认只有背景材质变淡，文字和控制按钮仍然清楚。
4. 调整悬浮窗大小、拖动位置、滚动长列表与歌词，确认操作手感与 1.2 一致。
5. 收为音乐图标后再展开，切换其他应用并使用通知栏播放控制。

现有歌单、音质、歌词排版、播放队列、历史与睡眠定时继续使用原有逻辑。此次没有新增或调整在线音源。
