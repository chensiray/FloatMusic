# Android 1.2 验收说明

本次为 `1.2.0-preview`，版本码 16。已在连接的 MTN-AN80（Android API 36）上保留数据覆盖安装，用户已授权发布双端 1.2。电脑端 1.2 已获用户验收，本次补齐手机端功能。

## 播放队列

在“更多 → 播放队列”查看队列。在歌单、搜索结果、在线歌单、榜单及最近播放的歌曲操作菜单中，选择“下一首播放”或“加入队尾”。当前歌曲不被打断；单曲循环或随机模式下，“下一首播放”仍应优先。

重点检查：

- 将同一首歌添加两次，分别拖动或移除，每次添加应独立处理。
- 长按手柄拖动排序，拖到列表边缘时继续滚动；点击手柄也可上下移或移到首尾。
- 播放歌单中间的一首，成功加载后队列应来自该歌单；失败时保留实际正在播放的歌曲。
- 移除当前项后音乐继续；清空后当前曲结束停止。保存的歌单不被删除。
- 退出重开后队列、顺序、当前项和暂停进度保留；已清空的队列保持为空。

## 最近播放

“更多 → 最近播放”最多保留 200 首成功开始播放的歌曲，同曲重播移到最前。可重播、加入队列或歌单，也可清空。

检查加载失败、只加入队列和切换音质不会产生额外历史。暂停后在本次运行中继续同一首歌，不应重复更新时间；清空后单纯暂停/继续也不应把刚清除的记录放回。重启后主动继续听歌会记录本次播放。

## 睡眠定时

“更多 → 睡眠定时”提供 15 / 30 / 60 分钟、自定义 1–180 分钟，以及“播完当前歌曲停止”。顶部定时图标可快速返回；页面显示剩余时间，支持取消。

建议用 1 分钟检查前后台到期、暂停期间到期，以及加载或切歌时到期。到期后应保持停止，不因延迟加载或音频焦点恢复而自动响起。“播完当前歌曲停止”应优先于单曲循环；重新启动应用时定时关闭。

## 通知栏与页面适配

媒体通知显示实际歌曲、歌手、进度和时长，提供上一首、播放/暂停、下一首、播放模式和音量操作；系统提供进度条时可拖动定位。音量操作打开悬浮卡片的竖直滑条，收起通知面板后调整。

检查卡片收起、欢迎页前台、切换应用和锁屏时的播放控制。文件选择期间，音量弹窗等待选择结束；取消导入后应恢复悬浮卡片。控件顺序、折叠与锁屏显示由手机系统决定。

检查浅色/深色、90–130% 设置范围内的最大可用缩放（按屏宽夹取）、小卡片和长列表：队列、最近播放、定时、设置应能正常滚动；操作菜单及音量滑条应显示在卡片上层。时间输入草稿和拖动排序不应被后台进度刷新打断。

## 已执行检查与边界

- 真机原生播放状态 10/10、原生界面 10/10 通过。状态检查使用隔离数据、静音 WAV 和真实 MediaPlayer；定时用可控时钟加速，不修改用户歌单或试听用户歌曲。
- 本地持久化 87 项、定时 3 组、通知策略 6 组及图标编译通过；原生界面契约及旧版契约共 15 组通过。
- Android 完整编译打包、APK 签名和构建源码核对通过；构建、交付与手机实际安装的 APK 校验值一致。Android 桥接改动后的电脑端控制器与界面回归 2/2 通过。
- 人工检查确认实际通知元数据与按钮、欢迎页的通知音量入口、本地文件选择及取消返回；文件选择期间的音量等待通过应用自身身份触发同一服务命令检查。

本次没有新增音乐接口，也没有重复请求线上音源；长时间锁屏和其他品牌省电策略尚未覆盖。实际歌曲播放、触摸手感及其他手机的页面适配仍需用户验收。详细记录见[验证说明](../VERIFICATION.md)，操作见[Android 使用指南](Android使用指南.md)。
