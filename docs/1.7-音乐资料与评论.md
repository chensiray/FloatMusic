# 浮音 1.7.0-preview.1 验收说明

本次提供 Windows 与 Android ARM64 本地预览，不发布远端。继承 1.6 preview.4 缓存歌词修复。

## 使用入口
- 电脑：播放器标题旁的信息按钮，或歌曲操作菜单中的“资料与评论”。
- 手机：更多→资料与评论；也可长按歌曲打开歌曲菜单，再选择“资料与评论”。
- 默认歌曲原目录来源。点击其他来源后先显示候选，确认同一版本再读资料，不改变正在播放的来源。
- 热门与最新分别加载。长评论支持展开/收起，最新列表可加载更多。手机已加载评论每20条一页，避免一次创建庞大原生视图树。
- 在线歌单显示封面及可获取的播放量、收藏数、评论数；保留简介展开、收起和复制。

## 数据边界（2026-10-31 实测）
- 网易云：歌曲详情、封面、专辑、发行日期、具体热门/最新评论及总评论数可读。
- QQ：歌曲详情、专辑封面、具体热门/最新评论及总评论数可读。评论使用详情返回的数字ID，不能把songmid直接作为评论编号。热门cmd=6的分页也位于comment字段。
- 酷我：现有目录资料继续可用；公开网页评论入口实测404，明确提示暂不可用，可切换其他来源。
- 歌曲播放量、收藏数并非每个平台公开提供；缺失不显示，不伪造数字。歌单统计明确属于歌单。
- 来源接口可能变化；网络失败和空评论分别处理，并提供重试。

## 缓存与性能
- 仅成功资料/评论覆盖本地快照，按平台、歌曲ID和排序隔离；失败可立即阅读旧内容，并显示可能过期。
- 评论快照限100份、总16MiB；单响应/单快照2MiB；每页最多20条，最多1000条。最新评论使用服务端原始页码，不因去重改变偏移。
- 封面异步读取；电脑使用Qt网络磁盘缓存32MiB，手机磁盘缓存32MiB与内存缓存4MiB，下载限2MiB并缩小解码尺寸。
- 独立资料请求不触碰播放/歌词请求代次。Android桥在状态不变时跳过大评论列表的JSON编码。
- 评论纯文本显示；不登录、不提交评论、不点赞、不同步个人收藏。
