# 浮音 1.7：资料评论、统一封面与歌词颜色进度

2026-11-02，经用户验收后发布。标签 `v1.7.0-preview`，Windows 与 Android 均保留验收通过的 `1.7.0-preview.3`；Android 版本码33，沿用原有签名。

## 歌曲资料与评论

点击标题旁的信息图标，或在歌曲菜单中选择“资料与评论”。显示封面、专辑、可获取的发行日期和评论数，阅读具体热门／最新评论；长评论可以展开，最新评论可以加载更多。在线歌单展示可取得的封面、作者与统计。

页面显示当前资料来源，默认使用歌曲原目录来源。切换来源时先选择匹配的歌曲版本，再读取资料；这一操作不会改变正在播放的歌曲。资料与评论只读，不登录、不发评论、不点赞，也不进行个人收藏同步。

网易云与QQ已有公开详情、评论的成功样本；酷我评论暂不可用，会明确提示并允许切换来源。服务没有返回的播放量、收藏数等统计不会显示为零。已有成功资料可离线阅读，页面会标明旧快照。来源接口可能变化，不能保证所有歌曲都有评论或全部统计。

## 双端封面与按钮

搜索、歌单、排行榜、队列、历史与缓存列表统一显示歌曲封面。缺失时异步补取；无法取得时显示一致的默认封面。通过“设置 → 通用与外观 → 显示歌曲封面”关闭。

手机标题旁的信息、下载图标与电脑版一致。点击下载图标手动保存当前歌曲和歌词，通过“设置 → 本地缓存”统一管理；此前离线缓存与自动容量清理继续保留。

## 歌词颜色进度

播放器内与独立悬浮歌词均增加从左向右的高亮颜色覆盖。默认开启，在“设置 → 播放器歌词”或“桌面歌词／独立悬浮歌词”中关闭“歌词颜色进度”即可恢复整句高亮，两处入口保存同一个开关。

按当前句到下一句的时间区间匀速覆盖，最后一句使用歌曲时长；无有效时间区间时保留整句高亮。歌词源只保证逐句时间戳，因此此效果不是逐字演唱对齐。长句换行按文字宽度依次推进，双语原文与译文同步；暂停、恢复、定位和歌词时间微调重新同步。

保留居中、曲线透明度、明暗主题、滚动、复制与点击穿透。动画复用布局与位图，暂停、隐藏、完成或手动浏览使当前句离屏时停止额外刷新。另合入音频已缓存但歌词缺失时补取歌词、避免旧缓存覆盖有效歌词的修复。

## English

FloatMusic 1.7 ships the accepted Windows and Android `1.7.0-preview.3` packages (Android code33, unchanged signing certificate).

- Read song details and actual hot/latest comments. View the metadata source and confirm a matching version when switching it, without changing playback. Public capabilities vary by source; unavailable statistics are not shown as zero. Comments are read-only, and previously fetched snapshots can be read offline.
- Consistent artwork across song lists, with asynchronous fetching and a default image. Artwork can be hidden under General & appearance. Matching information and download icons sit beside the title on both platforms.
- Left-to-right highlight progress in player and independent floating lyrics, including wrapped and bilingual text. One persistent setting controls both. Existing line timestamps provide uniform progress within each line, rather than word-level singing alignment. Pause, seeking and timing adjustments stay synchronized, and unnecessary frame work stops when hidden, offscreen or complete.
- Preserve offline audio/lyric caching and fix missing lyric fetching when audio is already cached.

Extract the complete Windows ZIP and keep every DLL/plugin. The ARM64 APK supports Android 9+ and can update an older package with the same signature in place. Downloads and checksums are linked above. All 19 desktop regression groups passed; Android automated checks used an isolated emulator, followed by user acceptance. See [verification notes](../VERIFICATION.md) for scope.
