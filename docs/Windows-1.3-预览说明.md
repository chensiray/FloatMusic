# 浮音 1.3 电脑端视觉预览

本版从 1.2 的原始界面重新制作，只加入已选的 07A 珠光虹彩视觉。音乐卡片、导航位置、控件大小和顺序、字体排版、页面展开与滚动方式均沿用 1.2。

程序位于 `artifacts/v1.3-desktop-preview-2026-10-13/app/FloatMusic.exe`。双击程序，点击悬浮音符展开；再次启动程序也会展开已有窗口。运行库与程序保存在同一文件夹，移动时请一起移动整个 `app` 文件夹。

建议查看：

1. 紧凑音乐卡片的珠白底色、青蓝与粉紫玻璃边缘，以及原播放按钮的珠光高光。
2. 展开歌词、歌单与更多页面，检查原有排版与操作手感。
3. 打开音量、播放模式与歌曲菜单，查看统一的玻璃材质和文字清晰度。
4. 在设置中切换浅色、深色和跟随系统，调整原有缩放、不透明度与动效偏好。

虹彩集中在边缘和空白角落，正文阅读面保持实心低饱和底色。透明度只影响背景，文字和图标保留自己的颜色。

深色版使用更清楚的青蓝、粉紫玻璃轮廓，角部色雾柔和扩散；播放键为浓紫珠光和白色图标，弹层与选中项有独立层次。验收深色效果可进入“更多 → 设置 → 主题 → 深色”。原布局、字号与按钮大小保持 1.2，浅色材质不变。

真实截图与布局对照结果保存在 `artifacts/v1.3-desktop-preview-2026-10-13/layout-rebuild`；深色优化及浅色像素对照保存在同级的 `dark-polish` 目录。界面示例使用独立测试数据，不会写入正式曲库。本页说明 Windows `1.3.0-preview`；2026-10-15 已继续同步手机端，见 [Android 1.3 验收说明](Android-1.3-验收说明.md)。
