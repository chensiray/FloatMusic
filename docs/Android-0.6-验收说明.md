# Android 0.6 预览版

ARM64 APK，最低 Android 9，本轮版本号 `0.6.0-preview.2`，安装版本码 7。沿用原应用包名和本机调试签名，可用于覆盖原来的同签名预览版；不用卸载或清除应用数据。

按用户要求不运行自动化或主动交互测试。初版已覆盖安装，用户反馈功能未发现问题，并提出扩大歌词区域的建议；本轮据此调整布局与字号，覆盖安装后获用户认可，并授权上传 GitHub；没有逐项测试清单，不代表所有设备均已覆盖。

## 已同步的操作

- **播放模式**：下一首右侧的模式图标，向上弹出顺序播放、列表循环、单曲循环和随机播放。选中项带勾，自动保存。通知栏切歌也使用当前模式。顺序播放在歌单末尾停止，随机多首时不立即重复当前歌曲，单曲循环支持未加入歌单的在线试听。
- **逐句歌词**：在线歌词带时间标签时自动高亮当前句、略微放大并滚动。原文、译文、双语选择移至“更多 → 设置 → 歌词显示”，选择自动保存。手指翻看后暂停跟随，右下角箭头指向当前句，点击后返回并恢复跟随。没有时间标签时显示普通歌词。
- **歌词字号**：“更多 → 设置”中可调节 14–26 的歌词字号，默认 18，提供即时预览并保存；当前句比普通歌词大 2。普通文本歌词也使用该字号。
- **时间微调**：歌词工具栏的时钟图标，每次 ±0.5 秒，范围 ±10 秒，正值让歌词提前；点击中间数值归零。设置按歌曲保存。
- **恢复现场**：正常退出后重新打开并显示悬浮窗，恢复歌曲、进度和模式，保持暂停；点击播放再继续。在线音源会重新请求，避免使用旧地址。每五秒及暂停、跳转、切歌前、正常退出时保存，强制终止可能损失最后几秒。

## 页面适配

- 模式和微调菜单在卡片最上层显示，不新增底部空间，保持不透明；点击菜单外收起。向上空间不足时菜单内部可滚动。
- 歌词有独立滚动区，按实际控件高度分配屏幕剩余空间（160–420dp），取消原来的 184dp 上限；顶部工具合并为一排，播放按钮与标签缩至 48dp，减少歌词行间留白。翻看歌词不会同时拖动整个卡片；返回按钮固定在歌词区右下角。
- 卡片保留 90–130% 缩放，并受可用屏幕宽度限制；横屏或较短屏幕下整张卡片可滚动。菜单使用屏幕内的触摸尺寸，不随低背景不透明度降低可操作性。
- 切换主题、横竖屏或大小时重建布局并收起弹窗；重新打开悬浮卡片仍显示当前播放位置。

建议验收时关注首次播放无需刷新歌词、切歌后自动跟随、手动翻看与返回、菜单不被卡片遮挡、横屏及缩放后的控件触摸，以及退出重开后的续播位置。本轮未增加本地 LRC 导入或本地音乐自动匹配在线歌词。
