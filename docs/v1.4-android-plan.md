## 2026-10-20 歌词验收修订

用户真机反馈：独立透明歌词换句时出现横向闪动和跳越，并补充播放器内歌词缺少滚动效果。先以隔离测试包在 Android API 36 模拟器复现窗口身份、水平锚点、数据刷新打断动画及首两句目标始终为零的问题，再分别修正。没有修改用户设备或真实歌单。

修正后八个实际原生界面场景通过，包含手动浏览返回及关闭动效的直接定位；原有七套 JVM 回归通过。构建 `run-20261020-192523-a45f94a5` 生成同签名 `1.4.0-preview.1`（版本码 20），独立保存到 `artifacts/v1.4.0-preview.1-android-2026-10-20/`，SHA-256 为 `32cd5b394f5cb0344b84fc517d75e8f3d100edf3b6c993f714cf21c555411646`。详情见[歌词修复说明](Android-1.4.0-preview.1-歌词修复.md)。原生组件测试不替代完整 APK 的品牌真机验收。

## 2026-10-21 真机动效修订

用户确认独立歌词切句拖沓，长短句及播放器内歌词均卡顿。连接手机采样后，Android 13+ 改用单窗口与文字触摸区域，消除逐帧移动多输入窗口的开销；两处统一 260ms 快速起步的曲线。播放器保留浮点位移，并按高亮最大字号固定文字排版，避免整数停顿和高亮重排。
