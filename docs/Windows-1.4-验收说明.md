# 浮音 1.4 · Windows 预览

用户已确认 1.4 验收通过并授权发布，双端下载见 [1.4 Release](https://github.com/chensiray/FloatMusic/releases/tag/v1.4.0-preview)。下文保留开发期的验收入口与记录。

启动 `artifacts/v1.4-desktop-lyrics-2026-10-20/app/FloatMusic.exe`，首次仍显示圆形悬浮图标，点击展开播放器。

## 语言

打开 **更多 → 设置 → 语言与桌面歌词**，界面语言可选择简体中文或 English，立即生效并保存。歌曲名、歌手、用户创建的歌单名称与歌词原文保持原样。

## 桌面歌词

在同一设置区域打开“桌面歌词”，可选择 **1、3、5、7、9 行**，默认三行，并调整桌面歌词字号。圆形悬浮图标的右键菜单也可显示或隐藏桌面歌词。

- 窗口背景完全透明，仅显示居中的文字。当前句以紫色高亮并略微放大，上下文从中央向两端逐渐变淡、缩小。
- 只有歌词文字区域可拖动，松开后保存位置。文字外的留白可点击到下方应用；收起播放器不会隐藏桌面歌词。
- 歌词主题独立选择浅色、深色或跟随播放器，也可在歌词右键菜单切换。浅色用深色文字，深色用浅色文字，背景均透明。
- 右键歌词可锁定位置、打开设置或隐藏；锁定只固定位置，仍可右键解锁。
- 一行显示当前句；多行始终将当前句放在正中央。开头和末尾缺少的上下文留空。空间不足时自动缩小文字，屏幕可用区域变化后重新适配。
- 播放带时间轴的在线歌词时自动平滑滚动，拖动播放进度也会跟随。没有逐句时间信息时显示真实状态说明。

## 播放器歌词

原歌词页使用同样的平滑滚动。手动滚轮、拖动滚动条或方向键翻看时暂停跟随，点击“回到当前歌词”恢复。关闭“界面动效”后两处歌词直接定位，不播放滚动动画。

保持 1.3 的音乐卡片、页面布局与虹彩外观。本次预览仅更新电脑版，等待验收后再安排手机端。

验证记录：2026-10-20，13 组桌面回归测试通过。新增界面测试覆盖语言切换、错误提示、透明窗口、一至五行首尾对齐、平滑滚动、拖动保存和重启恢复；英文浅色、深色界面均已截图检查。可选的实时联网测试未启用。

歌词样式修订验证：13 组桌面回归再次通过，覆盖 1/3/5/7/9 行的首尾对齐、渐隐与缩放、独立主题与重启恢复。Windows 原生窗口检查确认文字外命中下方窗口、文字可拖动，右键菜单及工作区刷新正常；浅色、深色实际渲染均已截图检查。
