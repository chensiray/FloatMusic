# 浮音 0.8 双端验收说明

本版新增音乐排行榜，并统一调整 Windows 与 Android 的按钮、图标、间距和按压反馈。Windows 音源修订为 `0.8.0-preview.1`；手机最新修订为 `0.8.0-preview.2`，版本码 11，包含备用音源及列表手势修订。手机歌单与歌曲/歌单搜索结果可上下翻看，面板切换直接回顶。

2026-10-02，用户确认 Android 修订版验收无误，并授权上传 GitHub；未提供逐项测试清单。以下检查项保留供后续复查与其他设备验收使用，不代表全部播放、后台回退与适配场景均已通过。实际检查范围及安装状态见[验证说明](../VERIFICATION.md)。

## 备用音源

默认优先 GD 音乐台，失败后尝试原第三方接口和 INJAHOW，保持原歌曲编号。设置中可查看实际来源、请求音质和音频格式。INJAHOW 可能返回 MP3，选择 Hi-Res 不会将它标记为 Hi-Res 文件。

验收可先选择此前失败的 Cool Forest Rain，确认能开始播放、暂停、拖动进度并继续；切换音质时保留当前歌曲、进度和暂停状态。再检查通知栏切歌、锁屏后继续播放、耳机拔出暂停和重启恢复。全部来源不可用时应结束加载并显示错误，可点击重试。自定义 API 不会自动切换到公共来源。

## 排行榜

在 **更多 → 排行榜** 打开榜单列表，首次打开自动读取。热歌榜、新歌榜、飙升榜、原创榜优先显示，其他榜单保持服务返回的相对顺序；具体可用榜单由音乐服务决定。

榜单行显示名称、简短简介、服务提供的更新频率和歌曲数量。点击榜单进入详情，试听歌曲、加入当前歌单或整单导入当前歌单、收藏夹、新歌单；返回时回到原排行榜列表。

点击刷新重新获取列表。网络失败时显示原因及重试入口，保留同一服务此前取得的榜单；更换音乐服务会清空旧榜单。兼容服务需支持 `/toplist`，内置服务按 Lua 使用的 `/api/toplist` 请求。

榜单详情沿用歌单的读取和导入规则：单次最多读取 2000 首，歌曲数量不足时明确提示；播放依赖音源服务的实际可用性。本版不提供网易云账号登录、云端歌单同步或音频下载。

## 界面变化

- Windows 的普通按钮、图标按钮、输入与选择控件更紧凑，主播放按钮突出，次要操作降低底色和描边的视觉重量。
- Android 缩小按钮的可见底色和图标，同时保留点击范围；操作行与工具栏减少高度，给歌词和歌曲列表更多空间。
- 常用入口使用统一线条图标，浅色和深色分别提供对应的文字、底色、选中与按压状态。
- 点击提供轻量按压及释放回弹，可在设置中关闭界面动效；Android 同时遵循系统动画开关。
- 歌单和搜索工具继续随列表滚动，滚回顶部可操作；浮层仍位于卡片上方，歌词字号、自动跟随及返回当前句继续保留。

## 验收重点

1. 两端从“更多”进入排行榜，等待加载、刷新、失败重试；热歌榜等榜单可打开详情并返回。
2. 榜内歌曲试听和加入歌单，整单导入目标正确；不完整的榜单有提示。
3. 歌单、搜索、排行榜和设置在小屏、横屏或缩放后仍可滚动，长标题不遮挡按钮。
4. 按钮与歌曲排序手柄易于操作；按压动效不使相邻内容移动，关闭动效后按钮仍正常反馈。
5. 原有歌词空间、播放模式、收藏、多选、拖动排序、JSON 导入导出和重启恢复仍可使用。

## 运行方式

Windows 使用完整运行目录中的 `FloatMusic.exe`，保留 DLL 与插件；先退出旧版再打开新版。Android 使用 ARM64 APK，可按设备提示覆盖安装，打开欢迎页后点击显示悬浮窗。
