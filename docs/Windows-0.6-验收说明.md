# Windows 0.6 开发预览

本轮在 Windows 端加入播放模式、逐句歌词和播放现场恢复。修订 1 后用户反馈“未发现新问题”；手机同步版见 [Android 0.6 验收说明](Android-0.6-验收说明.md)。按用户要求未运行自动化测试或启动应用做交互测试，编译和打包不代表覆盖全部场景。

修订 1 针对两项反馈调整：模式菜单使用卡片顶层浮层，避免被置顶卡片遮挡；歌词时间轴生成完毕后单独通知界面，并在列表完成布局后定位当前句，修正首次播放需手动刷新才能跟随的问题。

## 使用

先通过“更多 → 退出浮音”退出已运行的旧版，再运行验收包目录中的 `FloatMusic.exe`。保留同目录的 DLL、插件和 QML 文件。新版沿用本机已有的歌单、收藏、音量及外观设置。

## 本轮验收重点

- **播放模式**：下一首右侧点击模式图标，选择框在按钮上方向上弹出，选中项带勾。支持顺序、列表循环、单曲循环、随机；手动上下首仍可切歌，顺序模式的自然播放在歌单末尾停止。随机模式多首时不会立即重复当前曲目。搜索试听未加入当前歌单时不会自动进入无关歌单，单曲循环可用于试听曲目。
- **逐句歌词**：播放带时间标签的在线歌曲后打开歌词，当前句用主题蓝色、稍大的字和左侧短线标记，自动跟随。滚轮、拖动、滚动条或方向键翻看后暂停跟随；右下角箭头指向当前句，点击返回并恢复跟随。保留原文、译文、双语选择，以及无时间标签时的普通阅读。
- **歌词微调**：歌词栏的设置图标打开微调框；每次 ±0.5 秒，最多 ±10 秒，正值让歌词提前。点击中间数值归零，每首歌独立保存。
- **恢复现场**：播放一首歌到中间，正常退出并重开，歌曲、进度和模式保留，保持暂停，点击播放后继续。在线曲目按歌曲编号重新取音源；本地副本丢失或网络失败会提示错误，可重试或选择其他歌曲。

每 5 秒保存一次播放现场，暂停、跳转、切歌前和正常退出时也保存。强制终止进程时可能损失最后几秒。当前歌单继续使用既有持久化设置，在线试听即使未加入歌单也可恢复。

本地歌曲本轮不增加自动匹配歌词或导入 LRC 的入口。
