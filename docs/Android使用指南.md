# Android 使用指南

适用于浮音 0.6 预览版 ARM64 版本，最低 Android 9。

## 首次启动

1. 安装 APK，打开浮音。欢迎页会保留在屏幕上，等待操作。
2. 点击“显示悬浮窗”，按系统提示允许浮音显示在其他应用上方。
3. 返回应用后使用音符图标；点击图标展开音乐卡片。若未授权，可回到欢迎页再次点击按钮。

系统询问媒体通知权限时，允许后可从通知栏控制播放。悬浮窗权限和通知权限分别管理，具体名称因手机系统而异。

## 悬浮播放

卡片上方包含歌名、歌手、进度、上下首、播放暂停和音量。拖动左上方“浮音”区域移动窗口；点击右上角减号收为图标。

- **歌词**：自动高亮并跟随当前句；手动翻看后点击右下角箭头返回。顶部时钟图标微调歌词时间，刷新图标重新获取歌词。原文、译文、双语选择和 14–26 字号调节位于“更多 → 设置”，设置自动保存。
- **歌单**：切换、新建、改名、删除歌单，播放或移除曲目。至少保留一个歌单。
- **更多**：搜索、收藏、导入音乐、设置、“收藏 / 取消收藏当前歌曲”及退出浮音。

三个按钮共用下方展开区，点击另一项切换，再点当前项收起。长内容在区域内滚动。

下一首右侧的模式按钮提供顺序、列表循环、单曲循环和随机播放，通知栏切歌遵循当前模式。正常退出后重开并显示悬浮窗，会恢复上次歌曲和进度，默认暂停。

## 导入与收藏

“更多 → 导入音乐”会打开系统文件选择器。支持 MP3、WAV、FLAC、OGG、M4A、AAC，单首不超过 30 MiB。选择文件后返回悬浮窗，点击播放即可试听；取消文件选择不会导入内容。

搜索结果可直接播放或加入当前歌单。在“更多”中收藏当前歌曲，“更多 → 收藏”打开“我的收藏”页面，可播放收藏、加入歌单或取消收藏。这些数据保存在手机本地，不会同步到电脑或网易云账号。

## 外观与声音

在“更多 → 设置”选择浅色、深色或跟随系统。整体大小为 90–130%，实际大小受屏幕可用空间限制；背景不透明度为 20–100%，文字与操作控件保持可见。点击“恢复大小、背景和位置”可恢复默认外观和位置。

设置中还提供五档在线音质、音频输出和可选的兼容 API 地址。蓝牙耳机需先与手机连接，应用列出的输出设备及路由效果取决于 Android 系统支持。

## 后台、返回与退出

收起卡片、返回桌面或切换应用后可继续播放。重新打开浮音会显示欢迎页并隐藏已有悬浮层，离开后恢复；欢迎页不会因已有悬浮权限而自动退到后台。

悬浮页中，返回键优先收起键盘，再收起展开区或回到图标。要完全停止播放，请使用“更多 → 退出浮音”或欢迎页的“退出浮音”。系统强行停止应用也会中止播放，不会自动重启。

若锁屏后被系统停止播放，请检查手机的后台运行和电池管理设置。不同品牌的规则不同，浮音无法保证所有省电模式下持续播放。

## 升级与兼容

同包名、同签名的新版通常可以覆盖安装并保留数据。若系统提示签名不一致，不要直接卸载旧版：卸载可能清除本地歌单、收藏和导入副本，应先确认安装包来源和签名。

本次构建使用调试签名；正式分发包的签名和覆盖安装兼容性需以对应版本说明为准。更多限制见[项目主页](../README.md)与[验证说明](../VERIFICATION.md)。
