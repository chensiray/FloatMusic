# 1.7.0-preview.2：统一封面与手机按钮

- 搜索结果、歌单、本地歌曲、播放队列、最近播放及缓存管理的歌曲行统一显示40像素封面；图片尚未加载、文件没有封面或来源不可用时，显示统一唱片默认图，不留空白、不改变行高。
- 保存搜索服务已有封面字段；队列、历史、歌单导入导出保留有效封面与专辑资料，修复整理后丢失封面的情况。
- 缺失封面按可见歌曲补取，双端共用解析结果、去重和缓存，最多两个资料请求同时进行。失败短时间不重复请求；关闭封面开关后不再提交新补取任务。
- 设置→通用与外观→显示歌曲封面，默认开启，关闭后收回封面占用的空间并保留选择。此开关针对歌曲列表，详情中的专辑资料仍可查看。
- 手机标题旁改为与电脑一致的信息、下载线条图标；信息直接打开资料与评论，下载直接手动保存。保留48dp触控区域、双语无障碍名称，以及不可用时禁用的状态。
- 更新版本号至1.7.0-preview.2 / Android versionCode32；继承前一预览版的资料、评论、离线播放与歌词修复。
