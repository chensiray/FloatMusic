# 双端 0.9 验收说明

Windows 为 `0.9.0-preview.2`，Android 为 `0.9.0-preview`，版本码 12。Windows 关闭旧版后从完整运行目录启动 EXE；Android 使用同签名 APK 覆盖安装，保留歌单、收藏与导入副本。实际构建、检查和手机安装状态见 [验证说明](../VERIFICATION.md)。

## 两端一致的歌词设置

打开 **更多 → 设置**，选择原文、译文或双语，字号 14–26、默认 18。查看预览，再回到歌词页，检查逐句与纯文本字号、当前句高亮及放大效果。重启后两项应保留；电脑的歌词页不再放翻译选项。

播放有时间轴歌词的歌曲，确认自动跟随；手动翻看后点右下角箭头返回，微调歌词时间后继续跟随。字号变大、双语与长句时应能正常滚动。

Windows 的“恢复大小、背景和位置”应恢复默认外观与有效屏幕内位置，保留主题、动效和歌词偏好，与手机行为一致。

## 手机多曲库与混合歌单

在 **更多 → 搜索** 输入框上方多选网易云、QQ 音乐、酷我音乐，默认全选；选择重启保存，全取消时提示至少选一项。切换到歌单搜索后仍查网易云歌单，榜单也仍为网易云。

创建一个歌单，从三个曲库各加入一首，再加入本地音乐。检查来源文字、上下首、歌词、收藏、排序、多选移动/复制。导出 JSON，再在另一端 0.9 导入，检查身份、来源及顺序；本地曲目只记录文件引用，跨设备不可访问时会跳过。旧网易云 JSON 继续可用，Android 0.8 等旧版本会跳过新增曲库。

QQ/酷我固定普通音质，设置应禁用无效音质选择；网易云保留原档位。自定义音乐服务仅影响网易云，其他两库仍使用内置接口。换源只保留同平台同编号，不自动替换跨库同名歌。

暂停 QQ 或酷我歌曲并拖动进度，退出重开应恢复歌名、来源、歌单和进度，保持暂停；再次播放会重新解析地址。

## 页面适配重点

手机重点检查搜索、歌曲列表和歌单的双向滑动，勾选曲库后输入框不失焦、结果更新后不吞掉手势；工具随内容滚动，返回顶部才显示。测试长歌名、长歌手名、双语大字号与已有窗口缩放，来源文字不应遮挡播放或整理按钮。

电脑重点检查歌词区留白、设置页滚动、字号两端值以及浅色/深色。遇到问题请附版本、平台/曲库、歌曲、步骤和错误文字。

第三方接口仍可能波动或缺少曲目，有限成功样本不代表所有歌曲可播。本版待用户验收。
