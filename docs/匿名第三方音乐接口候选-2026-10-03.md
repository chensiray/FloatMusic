# 匿名音乐接口实测与第三方替代来源

调查日期：2026-10-03。资料与初步 HTTP 采样为北京时间 14:59–15:09，随后使用新增脚本进行自动探测、Qt 解码和复测。本报告补充[此前的官方与自托管接口调查](./其他音乐平台官方与自托管接口调研-2026-10-03.md)，聚焦调用方不用登录、购买、付费 API Key 或个人 Cookie 的公开服务。

本文保留接入前的调查结论。后续双端 0.9 已接入 QQ、酷我歌曲库，酷狗未接入；当前行为与验证边界见[双端验收说明](双端-0.9-验收说明.md)和[验证说明](../VERIFICATION.md)。

资料来自服务作者文档和源码。请求使用本机既有系统代理，未使用 CookieJar、账号、API Key 或浏览器凭据。HTTP 文件头阶段携带 `Range: bytes=0-63`，最多读取 64 字节；Qt 阶段会另外加载播放器所需数据，静音取得解码后的 PCM，并检查暂停、定位和恢复，不受 64 字节上限约束。未保存音频文件、试听整首或验证长期稳定性。报告隐藏临时 URL 查询参数和音频路径。HTTP 200、业务成功、非空 URL、音频头、短时解码与整首播放分别判断，不相互替代。

酷我中转每次都把请求的 `bytes=0-63` 扩大为从 0 开始的整段 Content-Range，原始 CDN 则准确返回 0–63。作者的 [handleProxy 源码](https://github.com/Yuncan050115/ourcraft-music-api/blob/c421965cb04c309cb7656498e0d4a392fa452206/lib/app.js)确实转发 Range；结合“首次定位失败、复测成功”的现象，只能认为中转存在协议异常和波动，不能断言已经证明失败根因或已修复。应优先采用明确返回的原始 CDN 地址，并在接入时再测较晚位置、断流恢复和 Android 行为。

## 其他候选的排除原因

`https://api.i-meto.com/meting/api` 是 [MetingJS 作者源码内置地址](https://github.com/metowolf/MetingJS/blob/master/src/Meting.js)，不是猜测的镜像路径。15:02:07 匿名 `type=search&id=海阔天空`：`server=kugou` 返回 30 个 `{title,author,url,pic,lrc}` 对象；`tencent` 返回 `[]`；`kuwo` 返回一个缺失 `title`、空 `author` 的对象，却仍填入资源回调。后两者不能计为成功搜索。后续自动探测“两只老虎”得到同样的搜索结论，酷狗两条音频回调均 404，歌词仍成功。公开服务签名不等于调用方购买的 API Key；探测使用服务原样返回的回调，报告不刊出签名。

[清羽 Meting 主页](https://met.liiiu.cn/)公布 `/meting/api` 并链接 [xizeyoupan/Meting-API](https://github.com/xizeyoupan/Meting-API)，同时公告暂时仅供个人使用。本轮只读主页，没有把它用作业务探测目标。关联源码 README 的 QQ 搜索支持栏为不支持，GitHub 仓库元数据本次为 `archived=true`；不将主页列出的“搜索”笼统能力推广到 QQ。

`api.lolimi.cn` 在本次网页工具中读取失败，Jina Reader 于 14:59:52 返回 422、域名无法解析。这个结果只描述所用读取路径，不足以证明所有地区都永久失效。[`img.lolimi.cn`](https://img.lolimi.cn/)实际是图床并跳转登录页，未取得音乐接口文档；没有拼接网上流传但未经作者当前文档核对的路径。

## 接入浮音时的取舍

本轮找到了可调用的匿名替代服务，解决了部分搜索、解析和协议限制；并没有证明会员或付费曲可用。明确需要用户登录、购买或上传个人 Cookie 的路径按要求放弃。酷狗样本不能证明整个酷狗平台都不可播，但现有证据不足以启用它作为播放来源。

优先考虑 QQ：原生接口或 V3 搜索，落月 V3 普通音质解析，INJAHOW 按 MID 作为候选备用。酷我采用 Ourcraft 搜索和 LRC，优先检查接口明确提供的原始 HTTPS CDN URL；中转不宜作为唯一依赖。酷狗可单独接入搜索、歌词、歌单，暂不把失败的播放链路列为可用音源。GD 对网易云仍有对照成功结果，但对 QQ、酷狗、酷我直接改 source 参数无效。

调研基线 0.8 尚有网易云专用边界：[MusicApi](../src/musicapi.cpp)及 [Android AudioResolver](../android/src/org/floatmusic/player/AudioResolver.java)当时将在线解析固定为 netease，[PlayerController](../src/playercontroller.cpp)只接受 local/netease。接入需要双端增加平台适配和明确的 `tencent:MID`、`kugou:hash`、`kuwo:RID` 标识，同时更新收藏、歌单导入导出和恢复现场；不能把不同平台的 ID 当成网易云 ID。0.9 已完成其中 QQ、酷我的适配，以上源码链接指向当前实现。

播放时重新解析临时 URL，保留原平台 ID 与搜索元数据。对同平台的候选供应商设置请求超时、有限重试及短期失败熔断，遇到空地址、业务失败、非音频内容或明确付费条件即停止该路径；播放接口失败不必让元数据搜索一起失效。Qt 本机短时成功尚不能替代 Android、整首播放、较晚位置跳转及长期稳定性验收。

## 复现方法

新增测试工具仅使用 Python 标准库。以下命令从仓库根目录运行；可将 `$probePython` 换成自己的 Python 3.12 路径。

```powershell
$probePython = 'python'
& $probePython -B -X utf8 scripts/probe_music_apis.py --providers qq qq-legacy kugou kuwo gd i-meto ourcraft vkeys injahow --query '两只老虎' --max-tracks 2 --playlists --playlist-query '儿歌'
```

默认每次请求间隔 0.3 秒、网络超时 8 秒，每个平台与提供方组合最多取 2 首（由上例指定）。`--proxy auto` 只读取启用的 Windows 系统代理；需要比较直连时使用 `--proxy none`。不用参数改动 TLS 校验，也不接受 Cookie 或 Authorization。默认产物位于 `artifacts/music-api-probes/时间戳/`；没有 `--qt-probe` 时仅做接口和文件头检查。终端的 `response` 行为初步响应分类，空 URL/无效曲目等最终分类以输出报告和 `Final outcomes` 为准。进程正常退出表示探测运行完成，不表示每个接口可用。

若要复现本轮静音播放测试，可用本机 Qt 6.11.2 MinGW 编译独立辅助程序：

```powershell
$qtRoot = 'C:/Qt/6.11.2/mingw_64'
$qtTools = 'C:/Qt/Tools/mingw1310_64/bin'
New-Item -ItemType Directory -Path artifacts/music-api-probes/qt -Force | Out-Null
& "$qtTools/g++.exe" -std=c++17 -O2 tests/music_api_playback_probe.cpp -o artifacts/music-api-probes/qt/music_api_playback_probe.exe -I "$qtRoot/include" -I "$qtRoot/include/QtCore" -I "$qtRoot/include/QtMultimedia" -I "$qtRoot/include/QtNetwork" -L "$qtRoot/lib" -lQt6Multimedia -lQt6Network -lQt6Core
$env:PATH = "$qtRoot/bin;$qtTools;" + $env:PATH
& $probePython -B -X utf8 scripts/probe_music_apis.py --providers vkeys ourcraft injahow --sources tencent kuwo --query '两只老虎' --max-tracks 2 --check-origin --qt-probe artifacts/music-api-probes/qt/music_api_playback_probe.exe --qt-bin "$qtRoot/bin"
```

辅助程序从 stdin 接收短期 URL，不放进命令行或诊断日志；每条音频最多等待约 10 秒。静音解码后暂停，跳到 5 秒或短曲中点，恢复播放并检查新缓冲与位置推进。`--check-origin` 仅用于作者 `/proxy` 明确返回的 `url` 参数对照，不生成权限参数。

工具自检包括 HTTP 200 业务错误/付费提示、嵌套 QQ 错误、假音频、JSONP、地址验证、报告脱敏、传统接口表单 POST，以及本地合成 WAV 的真实 Qt 解码与 HTML 假音乐拒绝。11 项全部通过，其中 2 项需要编译上述辅助程序：

```powershell
$env:QT_MEDIA_BACKEND = 'ffmpeg'
$env:FLOATMUSIC_QT_PROBE = Join-Path (Get-Location) 'artifacts/music-api-probes/qt/music_api_playback_probe.exe'
& $probePython -B -X utf8 tests/music_api_probe_tests.py -v
```

未设置 `FLOATMUSIC_QT_PROBE` 时，2 项 Qt 自检会明确标为跳过。

本轮新增本报告、Python 探测脚本、工具自检和独立 Qt 辅助程序；播放器功能未改动，尚未完成双端接入。没有安装后端、提交 Git、登录、购买或获取个人 Cookie。
