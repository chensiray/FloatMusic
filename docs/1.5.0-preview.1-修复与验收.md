# 浮音 1.5.0-preview.1：歌词末句与全文复制

日期：2026-10-26；Android versionCode：24。保留原有布局、虹彩视觉、1.4 审查修复和 1.5 悬浮歌词设置，本次只生成本地验收包。

## 使用变化

- 手机悬浮播放器内，手动上下翻看后滚动到底，末句不再被裁掉下半部分。
- 双端长按播放器内任意歌词，复制当前歌曲的**全部歌词**，按原文／译文／双语模式处理。双语逐句交错，缺少译文时不插入提示文字；纯文本歌词也支持。
- 长按本地歌单、在线歌单详情、搜索歌单或排行榜中的简介，复制完整原文，保留换行、表情和用户输入的字符，不复制显示省略号。
- 空歌词、空简介和占位提示不覆盖剪贴板；复制成功显示短提示。手动拖动不误复制，简介短击编辑／打开仍保留。
- 独立透明桌面歌词的长按仍用于打开歌词设置。

## 末句裁切根因与修复

按用户补充的“原文、字号 16、行距 1.5”在实际 Android View 中复现。歌词列的上下留白用于首末句居中，但列仍保留默认 `clipToPadding=true`，缩放后的末句字形被留白边界提前裁切。

仅关闭内层 `LyricColumn` 的 padding 裁切，外层 ScrollView 继续负责可见区域裁切。没有改变字号、行距、歌词跟随时间或原有布局。

同一原生场景修复前，文字底部为 446.21，而父层可见底部为 442；修复后可见底部为 447，完整容纳字形。真实截图同时确认末句恢复完整。回归还覆盖 16/18/30 字号与 0.8/1/1.5 行距的九种组合、短中文及长双语末句，并检查实际字体绘制没有超出自身行高。

## 复制手势的边界修复

Android 可长按 TextView 会先接收 DOWN，原来的 ScrollView 触摸监听因此漏掉手势开始。现从父层分发入口观察手势，保留手动翻看和返回当前句；实际拖动回归先红后绿。

新增简介长按后，排行榜简介也会接收普通短击；已将短击转发到原卡片，长按仍消费事件。实际同位置的长按复制、不导航、随后短击打开经过先红后绿验证。Android 大写 LRC 元数据清理也已与桌面保持一致。
