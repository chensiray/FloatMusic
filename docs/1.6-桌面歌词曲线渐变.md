# 1.6.0-preview.1：电脑版桌面歌词曲线渐变

上一版为提高可见度，采用了靠近中心衰减很慢的二次曲线。例如九行、中心 100%、边缘 55% 时，中心向外约为 100%、97%、89%、75%、55%，邻近行显得几乎同样突出。

本次电脑版改为归一化指数衰减：`edge + (peak - edge) * (exp(-2*t) - exp(-2)) / (1 - exp(-2))`，其中 `t` 为到中心的距离除以最外侧行的距离。

同样设置下，中心向外约为 **100%、80%、67%、60%、55%**。中心保持最强，邻近行随距离明显降低，上下对称；滚动时使用连续位置计算，避免跳档。保留中心和边缘两个可见度设置、明暗主题、文字描边和空行过滤。单行模式以及用户将两个端点设成相同数值时仍遵循原来的设置含义。

开发版本更新为 `1.6.0-preview.1`。电脑版完成后，Android 独立悬浮歌词已同步相同曲线，版本为 1.6.0-preview.1（versionCode 27），通过覆盖安装保留现有歌单与设置。

验证：回归测试先确认旧曲线不满足中间层级的衰减要求，再检查新曲线的端点、上下对称、逐行下降以及滚动位置的连续性。构建日志、测试结果和原生截图保存在 `artifacts/v1.6/`。

Android 验证：7/7 原生模拟器专项通过，包括曲线端点、明暗截图、空行、滚动和跨应用点击穿透；3 行/9 行绘制间隔 p95 约 18.4/18.9ms。2026-10-28 已通过 adb install -r 覆盖安装到连接的 MTN-AN80，系统确认 versionCode 27、versionName 1.6.0-preview.1，启动返回 Status: ok。手机实际歌词效果由用户继续验收。
