# 1.6.0-preview.2 本地缓存与离线播放

## 使用方式

- 在歌曲菜单选择“保存到本地”，或在播放器歌名旁点击保存按钮。歌单菜单可批量缓存；在线歌单只缓存当前已加载的歌曲，入口显示数量。
- 在“设置 → 本地缓存”管理下载任务、占用空间、手动保存和自动缓存。支持播放、长期保留、取消、重试、补取歌词、删除及批量清理。
- 完成下载后，原歌单、队列、历史记录和缓存管理页均可播放本地副本。关闭并重新打开应用后仍可使用；实际音质、歌曲身份和歌词偏移保留。
- 音频和原文、译文分别显示状态。音频完成即可离线播放；歌词尚未获取时可联网后单独补取。已有歌词不会因一次重试失败被清空。

## 默认设置与空间管理

- 自动缓存默认开启，容量为 1 GB，可选 256 MB、512 MB、1 GB、2 GB、5 GB。
- Android 默认仅在 Wi-Fi 下自动缓存。等待 Wi-Fi 和关闭自动缓存后暂停的任务会显示对应状态；手动保存可能使用移动流量。
- 手动保存长期保留，不计入自动缓存限额，但计入总占用。自动缓存按最近使用清理，当前歌曲和准备播放的缓存受保护。
- 清理前确认范围与大小。播放中删除会延后到文件不再使用；重新手动保存可撤销待删除状态。只清理应用管理的缓存，不删除用户导入的原始音频。
- 缓存保存在应用数据目录内。第一版不提供导出音频、指定目录、云同步及跨进程断点续传。

## 实现与边界

- Windows 由独立 C++ 模块下载和持久化；Android 由 Java 缓存模块独占索引和文件，播放服务负责媒体路径，Qt 提供歌词获取与解析。
- 音质回退按实际音质去重，保留请求映射。缓存管理页点选某个音质时会播放该条目，不受全局音质偏好改选。
- 下载先写临时文件，完整提交音频和原子索引后才显示可离线。拒绝错误响应、HTML、截断及未请求的部分音频；取消和退出清理临时内容。
- 下载过程中计算摘要。启动和查询使用文件大小、媒体头与高精度修改时间做轻量检查，实际播放器解码失败后撤销可用状态，避免启动时读取整个缓存库。
- 磁盘损坏或索引丢失无法重建歌曲元数据时会回收无关联的托管文件，需要重新缓存。缓存不是音乐文件备份。
- Windows 若在音频完成、歌词返回之前退出，可在管理页手动补取歌词；不会为了播放已有缓存等待在线歌词。
