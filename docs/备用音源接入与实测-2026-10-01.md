# 备用音源接入与实测 · 2026-10-01

用户反馈原第三方接口反复 HTTP 523 后，要求查找可用来源并接入。此前诊断见[稳定性分析](第三方音源稳定性分析-2026-10-01.md)。本次接入范围为 Windows 和 Android 的在线音频解析与失败回退，搜索、榜单、歌单、歌词仍使用原有元数据服务。

## 已接入来源

| 来源 | 官方公开协议 | 本次结果 |
|---|---|---|
| GD 音乐台 / GD Studio | `https://music-api.gdstudio.xyz/api.php?types=url&source=netease&id=歌曲编号&br=128/192/320/740/999`，JSON 的 `url` 为音频地址，`br` 为源返回码率 | 两首歌的地址、Range 音频头与实际解码播放通过 |
| INJAHOW Meting | `https://api.injahow.cn/meting/?server=netease&type=song&id=歌曲编号`，JSON 数组中的 `url` 为回调地址，随后重定向到音频 | 两首歌实际解码播放通过，样本为 MP3 128 kbps |
| 原第三方接口 | `https://www.byfuns.top/api/1/?id=歌曲编号&level=音质`，纯文本地址 | 保留为第二顺位；此前实测跨歌曲/音质 HTTP 523，不据此声明恢复 |

GD 官方文档更新日期为 2026-09-16，说明公开 API 的来源署名、非商业学习用途及每五分钟最多 50 次请求规则；浮音保留 GD 音乐台来源说明，每个解析器五分钟内最多 45 次 GD 请求，达到上限时尝试其他来源。此限制不能替代服务端按 IP 或多个设备统计的限流。

依据：[GD 官方 API 文档](https://music-api.gdstudio.xyz/api.php)、[GD 音乐台](https://music.gdstudio.xyz/)、[作者对开发者 API 的说明](https://github.com/UnblockNeteaseMusic/server/issues/1395)、[INJAHOW 官方参数说明](https://api.injahow.cn/meting/index.php)、[INJAHOW 实现](https://github.com/injahow/meting-api/blob/master/index.php)。

## 实测范围

独立 Qt/C++ 探测先验证公开服务，再用浮音实际 `MusicApi::resolveAudio` 与 Qt Multimedia 复测；播放器静音，通过收到解码音频、暂停保持进度、跳转到约 10 秒并继续播放判断成功，不代替完整曲目或听感验收。

| 曲目 | GD | INJAHOW |
|---|---|---|
| Cool Forest Rain，Dan Gibson，网易云编号 `1220792` | 请求 `br=999`，FLAC；独立音频头解析为 24-bit、44100 Hz。实际解析器播放通过，源返回码率 1482 kbps | MP3 128 kbps；实际解析器播放通过 |
| 海阔天空，编号 `347230` | 请求 `br=320`，MP3 320 kbps；独立播放通过 | MP3 128 kbps；独立播放通过 |

用户提供的标题为“Coll Forset Rain”，以上采用搜索得到的最接近曲目；如实际收藏中的歌曲编号不同，需另行对照。位深与采样率只说明这个源文件的格式，不用于证明母带质量。

网络条件有明确差异：第一轮强制直连时 GD、I-METO、Paugram 超时，INJAHOW 能取得回调但 CDN 超时；使用电脑现有系统代理后 GD、INJAHOW 均可播。浮音实际解析器按系统配置请求，真实播放复测清除了进程的代理环境变量，仍通过。未修改系统代理或关闭 TLS 校验，不能推断其他网络必然可用。

另两项候选未接入：I-METO 在代理路径返回 HTTP 500；Paugram 的样本链路出现 HTTPS 到 HTTP 的重定向，被现有安全重定向策略拒绝。未为接入放宽 TLS 或降级重定向保护。

## 双端回退行为

1. 默认优先 GD；不成功时尝试原接口，再尝试 INJAHOW。各来源使用同一网易云编号，不按同名搜索替换曲目。
2. 每次接口或音频头请求最多约 6 秒，地址解析链最多约 24 秒；音频准备有单独超时。每个来源在一次回退中最多使用一次，不无限循环。
3. 响应限制 64 KiB，播放地址最多 8192 字符；音频探测只请求头部 64 字节，验证常见音频签名，保留签名查询参数和最终重定向地址。
4. 接口连接失败或非成功 HTTP 状态进入 30 秒冷却；单首缺失、空地址和音频 CDN 错误不将整个来源长期关闭。用户点击重试会清除故障冷却，立即重新检查服务，但不绕过请求频率限制。
5. 地址正确但播放器加载/解码失败时继续尝试其他来源。保留所选曲目，尽量恢复进度和播放/暂停意图；手机后台自动切歌使用相同来源规则，失败时保留目标曲目供手动重试。
6. 显式配置兼容 API 时只访问该服务。设置显示来源、请求音质和实际格式；GD 的返回 `br` 按码率展示，不从其数值推断位深。

两种新来源是不同的托管接口，仍共享网易云内容及部分 CDN；并非两个完全独立的曲库。未加入账号登录、付费授权绕过、在线音频下载或跨平台同名匹配。

## 验证与交付

QtTest 新增回归覆盖 GD 音质参数、签名保留、HTTP 523、错误页面、超时回退、来源冷却、请求取消、来源显示、暂停/进度保留和损坏音频的解码回退。Android 测试在桌面 JVM 运行 APK 所用的实际 Java 解析器，对照同类本地 HTTP 响应；测试 JSON 库仅用于本地 JVM，APK 继续使用 Android 自带库。

独立复核另修正手机恢复进度时出错可能卡在加载、加载期间暂停被旧自动播放参数覆盖，以及临时音频焦点等待被回退清除的问题。这些服务生命周期修订已经编译，尚未进行真机验证。

版本为 `0.8.0-preview.1`，Android 版本码 10；完整构建、回归结果和安装状态见[验证说明](../VERIFICATION.md)。原始音频日志可能包含临时签名 URL，只存放在 Git 忽略的 `artifacts/`，未作为固定地址写入应用或文档。
