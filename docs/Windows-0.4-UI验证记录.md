# Windows 0.4 界面优化验证

界面及回归测试日期：2026-09-20。打包程序启动确认：2026-09-21。

## 本轮变化

- 版本号保持 0.4.0；仅优化 Windows 界面，Android 原界面保留在 `qml/AndroidMain.qml`。
- 提供浅色、深色、跟随系统，保存外观选择。
- 侧栏分为搜索、本地音乐、歌单、正在播放、设置；收藏预留为不可点击的“待开放”入口。
- 底部固定播放栏提供播放/暂停、上一首/下一首、进度、音量、音质和歌词入口。扬声器按钮展开音频输出设备选择。
- 明确下拉框文字和选中态；已播放部分在滑块左侧高亮。主窗口顶部可拖动，右下角可调整大小。
- 本地音乐页展示当前歌单中的本地文件；本轮不增加独立全局音乐库或收藏业务。
