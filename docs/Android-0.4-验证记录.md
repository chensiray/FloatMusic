# Android 0.4 手机适配验证

更新：用户审核后反馈了悬浮窗空白区域、低不透明度无法操作、大小仅调宽度三项问题。本报告的通过项不代表这些场景已通过；问题在 0.4 保留，后续修复，见 [BACKLOG.md](../BACKLOG.md)。用户随后授权提交并上传 0.4，以下“本地审核”描述原验证阶段。

日期：2026-09-21。设备：荣耀 MTN-AN80，Android API 36，ARM64，1200 × 2640，屏幕密度 520。Qt 6.11.2 / NDK 27.2.12479018 / JDK 21。版本保持 0.4.0，versionCode 4；本地审核，不上传 GitHub。

## 变更

- AndroidMain 使用与桌面相同的 Main 组件；手机采用底部四页导航、48dp 触摸控件、独立歌词页和两行播放控制。设置与歌词内容可滚动。
- 浅色、深色、跟随系统；下拉框明确文字与选中态。原生悬浮页同步主题，深色系统栏使用浅色图标。
- 搜索及歌词由共用 C++ API 层提供；原生 MediaPlayer 前台服务解析内置/自定义音频接口，支持五档参数、直接试听、切换档位保留位置和暂停状态。
- 接口响应、网络等待和音源准备时间有限制；失败可重试，已有可用音源不因地址解析失败而丢弃。
- 返回键在键盘显示时先隐藏键盘，否则退到后台；保留显式退出。
