# Windows 1.1 验收说明

本次为 `1.1.0-preview.2` 桌面修订，用户于 2026-10-08 确认验收无误。Android 同步为 `1.1.0-preview.1`，见 [Android 验收说明](Android-1.1-验收说明.md)。先在“更多 → 退出浮音”关闭旧版，再运行完整修订目录中的 `FloatMusic.exe`；原有歌单、收藏、设置和恢复现场继续使用。

## 曲库音质

在“更多 → 设置 → 播放音质”分别调整网易云、QQ 音乐、酷我音乐。无歌曲或播放本地音乐时也能设置；三个偏好独立保存，网易云沿用原有设置。更改正在播放歌曲所属曲库的音质会重新加载，并保留进度及播放/暂停状态。更改其他曲库不打断当前播放。

| 曲库 | 可选档位 |
|---|---|
| 网易云 | 标准、较高、极高、无损 FLAC、Hi-Res |
| QQ 音乐 | 标准、高音质 320、无损 FLAC、实验母带 |
| 酷我音乐 | 标准、高音质 320、无损 FLAC |

QQ 的高档通过现有落月接口请求，酷我接入公开 mobi 音频解析。设置下方展示请求档位与实际格式、可识别的采样规格和码率；档位不可用时尝试同曲较低档。实验母带仅在明确选择时请求，文件较大，可能增加加载时间；高采样规格不证明原始母带品质。第三方接口和歌曲权限可能变化，无损不保证每首可用。

建议先对照 QQ《星》（杨宗纬）及酷我免费曲目，切换 320 / FLAC，查看实际规格；再试听其他歌曲。酷我若返回不同歌曲、非歌曲类型或与目标时长不符的音频，应该显示错误；有明确目标时长的正常短歌可以播放。搜索、恢复现场和歌单 JSON 会保留有效时长；缺少目标时长的短音频会提示无法确认完整性。出处与样本见[高音质调研](QQ音乐与酷我音乐高音质接口调研-2026-10-06.md)。

## 音量与歌词

音量按钮在上一首、播放/暂停、下一首、模式按钮同一行，点击向上展开竖直滑条。拖动滑条向上加音量，向下减音量；可使用上下方向键，点击面板外或按 Esc 收起。检查 0 / 50 / 100 及重启保留，不应额外占用卡片下方一行。

设置 → 歌词的字号范围改为 **10–30**，默认 18；当前句继续增加 2 号并高亮。逐句歌词取消固定行间空隙与最小行高，默认使用 **1 倍自然行高**，每行高度随字号、换行及双语内容变化。检查最小、最大字号、原文/译文/双语、手动翻看后返回，以及退出重启后的保留。

字号下方新增 **行距 0.8–3.0 倍**，步进 0.1，默认 1.0 倍；下面的两行预览实时展示效果。逐句和可选择复制的纯文本均应用行距，高亮标记保持靠近当前文字。检查 0.8 / 1.0 / 3.0 倍、长句换行、双语和手动翻看状态，以及退出重启后保留。异常旧设置恢复为 1.0 倍。

## 设置适配

设置分为播放音质、歌词、外观、搜索与服务，输出设备归入播放区域，自定义网易云地址默认折叠。检查浅色/深色、90% / 140% 缩放和长设备名称；页面应能滚动到底，选择菜单与竖直音量面板应浮在卡片上方。

验收重点为播放、音质切换及页面适配；自动回归与接口取样记录会另行保留，不能替代用户验收。
