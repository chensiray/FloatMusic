# 双端 1.0 验收说明

2026-10-06 用户反馈验收无误。当前发布版本见 [1.0 Release](https://github.com/chensiray/FloatMusic/releases/tag/v1.0.0-preview)，下列步骤也可用于升级后的复查。

Windows / Android 均为 `1.0.0-preview`，Android 版本码 13。桌面先退出旧版，再运行完整运行目录的 FloatMusic.exe；手机可用同签名 APK 覆盖安装。已有歌单、收藏、歌词设置和播放现场继续保留。构建、接口与检查状态见[验证说明](../VERIFICATION.md)。

## 歌单与榜单

打开更多 → 搜索 → 歌单，勾选网易云、QQ 音乐、酷我音乐，搜索“纯音乐”等关键词。检查各曲库结果、来源、简介、歌曲数量、长标题换行和列表滑动。全部取消时按钮应禁用，按回车或手机键盘搜索也应提示选择曲库。

打开更多 → 排行榜，切换三个平台。QQ 榜单目录实时取得；酷我提供热歌、新歌、飙升三个入口，点击时读取实时曲目。加载时直接切换平台、快速返回并重开，旧请求不能覆盖新平台。

进入歌单或榜单后查看简介、作者、总数和已读取数量。试听歌曲，再整单导入当前歌单、收藏夹或新歌单。不同平台同名歌保留各自身份；导出 JSON 后可以在另一端 0.9 / 1.0 继续导入。歌单信息可用不保证所有歌曲可播，音频仍使用各平台既有解析方式。

## 搜索显示数量

更多 → 设置 → 搜索显示数量，可选 10 / 20 / 30 / 50 / 100，默认 30。它是所有勾选曲库合计上限，歌曲与歌单共用。修改后重新搜索，结果应不超过选择值；曲库没有足够匹配项或部分请求失败时可能更少。多平台结果轮流取出，来源不会被第一家占满。

选择 50 或 100 后退出重开，检查设置保留；同时确认歌词翻译、字号、音质和原有播放状态没有被重置。

## 链接导入与页面适配

在歌单管理中使用剪贴板导入 QQ 完整链接 `https://y.qq.com/n/ryqq/playlist/7593082970` 或酷我完整链接 `https://www.kuwo.cn/playlist_detail/3677150229`；网易云链接与裸数字 ID 继续可用。短链接先打开再复制完整地址。

手机重点检查小悬浮窗下的横向选择、搜索输入焦点、结果更新、双向滑动、榜单长标题以及设置数量菜单。电脑重点检查浅色/深色菜单层级、设置页滚动、长简介与歌曲数量。顶部按钮仍随列表滚动，到最上方才显示。

第三方接口可能超时或限流。若失败，记录平台、关键词/歌单、操作步骤与错误文字，便于区分接口故障和页面问题。
