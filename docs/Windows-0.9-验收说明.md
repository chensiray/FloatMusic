# Windows 0.9 多曲库验收说明

这是首版 Windows `0.9.0-preview.1` 的历史验收说明。当前 Windows 已修订为 `0.9.0-preview.2`，Android 为 `0.9.0-preview`（版本码 12），新增歌词设置同步与手机多曲库支持，最新入口见[双端 0.9 验收说明](双端-0.9-验收说明.md)。关闭旧浮音后，从完整运行目录启动 `FloatMusic.exe`；单实例机制会让重复启动唤起旧进程。

## 搜索与来源

打开 **更多 → 搜索音乐**，在搜索框上方多选网易云、QQ 音乐、酷我音乐。默认全选，选择会保存；全部取消时搜索按钮不可用，按回车会提示至少选择一项。更改选择后重新搜索。歌曲按平台分组顺序展示，第二行显示歌手与来源；单库失败时保留其他库的结果并提示失败来源。

搜索工具随列表滚动，回到顶部可重新选择曲库或搜索。`Ctrl+F` 可回到搜索框。切换到“歌单”时仍查找网易云歌单；排行榜也仍为网易云。

## 混合歌单

建议创建一个验收歌单，从三个曲库各加入一首，再加入一首本地音乐。检查连续切歌、逐句歌词、收藏、拖动排序，以及多选移动和复制。相同标题、相同数字编号但不同平台的歌曲保留为不同曲目；相同平台的同一编号按原有规则去重。

导出该歌单为 JSON，再导入新歌单，检查来源、顺序和名称；可分别测试文件与剪贴板导入。旧版网易云 JSON 继续可用。文档不包含音频文件或临时播放地址，本地文件在目标电脑不存在时会跳过；Android 0.8 会跳过 QQ、酷我曲目并提示。

## 播放、音质与恢复

QQ 与酷我固定普通音质，设置中的音质下拉框禁用，显示实际音源信息；切回网易云后恢复原先选定档位。来源请求失败时仅在同一平台、同一编号内尝试备用，不用跨库同名歌替换。

播放 QQ 或酷我歌曲，暂停并调整进度，再退出重开。预期恢复歌名、来源、进度与歌单，保持暂停；开始播放时重新解析地址。切歌后检查歌词、来源和音质信息是否正确更新。

设置中的自定义音乐服务仅影响网易云。QQ、酷我按搜索勾选访问内置服务，无需登录或购买。部分歌曲可能因接口故障或权限要求不能播放，错误会显示在卡片中。

## 页面适配与反馈

请重点查看卡片缩放 90%、100%、140%，浅色/深色，长歌名、长歌手名，多库结果滚动和不同来源切歌后的设置页。曲库按钮、来源文字不应遮挡操作，列表应保留原有可用高度。

自动检查范围见 [验证说明](../VERIFICATION.md)。若发现问题，记录曲库、歌名、操作步骤、音质和错误文字即可。本版尚待用户验收，第三方服务实测只代表请求时状态。
