# 浮音 1.5.0-preview.2：简介与设置整理

完成日期：2026-10-28。Android versionCode：25。

## 使用变化

- 本地歌单简介默认显示两行，在线歌单详情默认三行；实际放不下时出现“展开简介”，展开后可“收起简介”。短简介与空占位不显示按钮。
- 简介按当前窗口宽度判断是否需要折叠。切换歌单或更改简介后恢复折叠；本地简介的普通数据刷新保持当前展开状态。长按仍复制完整原文，桌面本地简介短击仍打开编辑。
- 设置首页只展示分类，点入后显示对应选项：通用与外观、播放与音频、播放器歌词、独立歌词、搜索与服务、关于浮音；Windows 另有快捷键。
- 子页面的返回键先回到设置首页，再返回“更多”。Windows Esc 和 Android 返回键采用相同层级。独立歌词的“歌词设置”直接到独立歌词子页。
- 保留原有虹彩视觉、偏好保存与中英文适配。搜索结果和榜单卡片继续使用简介预览，展开阅读在歌单详情内进行。
