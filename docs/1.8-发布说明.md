# 浮音 1.8 · 曲库整理与歌手作品

2026-11-21，经用户验收后发布。标签为 `v1.8.0-preview`，Windows 和 Android 使用已验收的 `1.8.0-preview.3`；Android 版本码 36，沿用原有签名。

## 收藏夹、歌单与离线歌曲

在收藏夹或歌单内输入歌名、歌手，筛选要找的歌曲。有效本地音频与已完成缓存显示离线标记，勾选“可离线播放”可在出门前确认哪些歌曲已能断网播放。标记会核验本地文件，缓存丢失或损坏后重新进入列表会更新结果。

“更多 → 导入音乐”中的本地文件选择器支持一次多选，继续使用 MP3、WAV、FLAC、OGG、M4A、AAC 和每首 30 MiB 的限制。逐文件验证并汇总成功、跳过数量，部分文件失败时保留成功导入的歌曲。Windows 同时检查音频和视频轨，取消导入会停止后续处理；Android 将文件复制结果与歌单保存结果分别反馈。

## 歌手资料与全部作品

在“更多 → 搜索音乐”切换“歌手”，选择网易云、QQ 音乐或酷我音乐，打开结果查看来源、可取得的简介与作品。

点击“显示全部作品”继续读取来源的后续页，作品搜索支持作品名、歌手和专辑，并继续查找后续页中的匹配项。作品可播放、加入队列、保存离线，或选择目标歌单导入全部／搜索结果。曲目按来源和编号去重，加载失败保留已读取内容并可重试；重复页会停止继续请求。

简介与完整作品列表取决于来源接口，部分来源或歌手可能缺少资料或只返回部分作品。页面显示已加载状态和错误提示。

## 当前歌曲定位与可用状态

歌单、搜索结果、歌手作品、队列和历史等列表高亮当前歌曲，点击定位箭头可跨页跳到对应位置。歌单或作品筛选隐藏当前歌曲时，定位会清除筛选；队列存在重复歌曲时定位到实际播放项。

来源明确标注受限，或解析响应明确说明版权限制时，在线歌曲显示“不可用”。网络故障仍可重试；成功播放和有效本地缓存会更新显示状态。

代码审查修复同时合入，批量缓存只提交一次索引，保存失败时回滚；修正 Windows 切换服务时的缓存解析恢复、Android 导入保存重试频率，以及构建与测试脚本中的问题。

- Search Favorites and playlists by song or artist. Offline badges and the Available offline filter verify local audio and completed cache files before a trip.

- Search artists across NetEase, QQ Music and Kuwo, read available biographies, load all available work pages, and search works by title, artist or album. Play, enqueue, save offline or import all works or filtered results into a chosen playlist. Failed pages preserve loaded results and can be retried. Catalog completeness depends on the source.
- Find the highlighted current track with a navigation arrow, including across pages and hidden playlist or work filters. Duplicate queue entries target the exact playing occurrence.
- Display Unavailable for explicit copyright restrictions. Network errors remain retryable, and verified playback or usable cached audio updates the displayed status.
- Reduce bulk-cache index writes, roll back failed saves, and fix import cancellation, Android import feedback and retries, and cache resolution after Windows service changes.
