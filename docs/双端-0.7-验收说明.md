# 浮音 0.7 双端验收说明

本版主要升级歌单，保留 0.6 的歌词、播放模式和现场恢复。按约定交由用户体验验收，没有运行自动化或主动交互测试。

Windows 修订 1（`0.7.0-preview.1`）：导出文件名默认使用歌单名称；歌单和搜索列表的顶部工具随内容滚动，向下浏览时不占固定空间，滚到顶部可再次使用。

2026-09-28：用户体验电脑端修订版后反馈“没有发现问题”，确认上传 GitHub。以下条目保留为操作说明和后续设备适配参考，具体验证范围见[验证说明](../VERIFICATION.md)。

## 使用入口

- **歌单**：选择当前歌单，显示名称、简介和歌曲数量。收藏夹在这里与其他歌单统一管理；旧收藏首次更新时迁入。
- **歌单操作**：新建、改名、编辑简介、复制整单、导入与导出。
- **多选**：选择若干歌曲，移动或复制到另一歌单，也可移除或仅导出选中曲目。复制 / 移动会自动合并目标里已有的歌曲。
- **排序**：使用歌曲旁的排序手柄拖动；也提供上下移操作。保存后重启保留顺序。
- **搜索 → 歌单**：查看在线结果的简介与数量，打开详情后试听，或加入当前歌单、收藏夹和新歌单。

## 导入导出

导出格式为 UTF-8 JSON，可存为文件或复制到剪贴板。在另一端打开导入面板，选择目标后从文件或剪贴板读取。还可以粘贴网易云完整歌单链接或数字 ID；短链接请先在浏览器打开，复制完整歌单链接。

每次最多 10000 首、8 MiB。无效和重复记录会跳过并提示数量。JSON 只包含曲目信息，本地音频不随 JSON 传输；本机不能读取的音频引用会被跳过。网易云接口只返回部分内容时，详情页会提示。

## 页面适配重点

- 手机短屏、横屏及 90%–130% 缩放下，歌单、详情和操作面板能滚动，按钮没有被裁掉。
- 键盘弹出后仍能编辑歌单名称和简介，关闭键盘能回到歌单；文件选择或取消后返回悬浮卡片。
- 长标题、长简介和大歌单不挤占播放控制；选择歌曲后工具条保持紧凑。
- 电脑小窗口和不同缩放下，弹层盖在卡片之上，选择和拖动不误触播放。
- 返回歌词页后，歌词显示空间、字号设置和自动跟随保持原有行为。
