# Windows 使用指南

适用于浮音 0.8 预览版（Windows `0.8.0-preview.1`）。启动后显示蓝色音符图标，单击展开播放器，拖动图标或卡片顶部可调整位置。

## 播放音乐

在“更多”中选择“导入音乐”或“搜索音乐”。也可将一个音频文件拖入图标或卡片，支持 MP3、WAV、FLAC、OGG、M4A、AAC，单首不超过 30 MiB。导入完成后点击播放。

播放卡片上可暂停、拖动进度、切换上下首及调节音量。下方的歌词、歌单、更多共用一个区域，再点当前按钮可收起。搜索结果中的“+”将歌曲加入当前歌单。

收藏当前歌曲请打开“更多 → 收藏当前”；“我的收藏”会打开内置收藏歌单，可播放、排序或多选整理。旧收藏自动迁入，收藏歌单名称固定且不能整单删除；移除收藏不会删除其他歌单中的同一曲目。

下一首右侧的模式按钮向上展开顺序、列表循环、单曲循环和随机播放选择。时间轴歌词高亮当前句并自动跟随，手动翻看后点击右下角箭头返回；歌词设置图标微调当前歌曲的时间。重启会恢复歌曲、进度及模式，默认暂停，点击播放继续。

## 搜索与整理歌单

在“更多 → 搜索音乐”中切换“歌曲 / 歌单”。在线歌单显示简介和歌曲数量，打开详情后可试听，也可整单导入当前歌单、收藏夹或新歌单。

“更多 → 排行榜”获取热歌榜等榜单，点击查看歌曲，试听或整单导入；返回回到榜单列表，可刷新重试。榜单内容和完整度由音乐服务决定。

歌单页的管理面板提供新建、改名、编辑简介、复制整单、导入和导出。拖动歌曲右侧手柄调整顺序，歌曲菜单也可上移或下移；筛选时先清空筛选再拖动。多选歌曲后，可批量移动、复制、移除或导出。

管理、切换歌单、筛选和搜索工具都随列表滚动；需要操作时滚回顶部。按 `Ctrl+F` 可展开搜索并回到输入框。

导出可保存为 JSON 文件或复制到剪贴板，保存文件时默认填入“歌单名称.json”。导入支持浮音 JSON，也可从剪贴板读取网易云完整歌单链接或数字 ID。单个 JSON 最多 10000 首、8 MiB，只包含曲目信息，不包含音频；目标设备无法访问的本地音频引用会跳过并提示。更多说明见[双端 0.7 验收说明](双端-0.7-验收说明.md)。

## 调整窗口和声音

- **收为图标**：点击右上角减号，音乐继续播放。
- **移动**：拖动卡片左上方“浮音”区域，或直接拖动音符图标。
- **缩放**：在“更多 → 设置”调整体大小，或拖动卡片右下角。范围为 90–140%，宽高和控件一起缩放。
- **透明度**：设置中的“背景不透明度”范围为 20–100%，不改变文字与按钮自身的透明度。
- **音频输出**：在设置中选择系统默认或指定设备。刚连接耳机时可点击“刷新”，然后选择对应耳机；同时检查 Windows 系统音量和浮音音量。
- **恢复外观**：设置中“重置”恢复 100% 大小及不透明度；主题可单独选择浅色、深色或跟随系统。
- **界面动效**：按钮按下和释放时提供轻量反馈，可在设置中关闭。

窗口会按屏幕可用区域限制大小和位置，内容较长时可滚动阅读。再次运行程序会唤起已有窗口。

## 退出与快捷键

“更多 → 退出浮音”停止播放并退出；图标右键菜单也提供退出。通过系统关闭窗口会退出应用，减号仅收为图标。

| 快捷键 | 操作 |
|---|---|
| Ctrl+F | 展开搜索并聚焦输入框 |
| Ctrl+O | 打开音频选择器 |
| Esc | 返回更多、收起展开区，或将卡片收为图标 |

快捷键在播放器窗口处于活动状态时使用，弹出菜单和对话框优先处理键盘输入。

## 运行与升级

解压运行包后运行 `FloatMusic.exe`，保留同目录中的 DLL 和插件。升级前退出旧版，再替换完整运行目录。歌单、收藏和设置保存在应用数据目录中；保留该目录即可延续已有数据。

没有运行包时，请参考[构建说明](DEVELOPMENT.md)。功能范围和在线服务说明见[项目主页](../README.md)。
