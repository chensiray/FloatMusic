# Windows 使用指南

适用于浮音 0.5.0。启动后显示蓝色音符图标，单击展开播放器，拖动图标或卡片顶部可调整位置。

## 播放音乐

在“更多”中选择“导入音乐”或“搜索音乐”。也可将一个音频文件拖入图标或卡片，支持 MP3、WAV、FLAC、OGG、M4A、AAC，单首不超过 30 MiB。导入完成后点击播放。

播放卡片上可暂停、拖动进度、切换上下首及调节音量。下方的歌词、歌单、更多共用一个区域，再点当前按钮可收起。搜索结果中的“+”将歌曲加入当前歌单。

收藏当前歌曲请打开“更多 → 收藏当前”；“我的收藏”中可播放、加入歌单或移除。收藏和歌单分别保存，移除收藏不会删除歌单中的曲目。

## 调整窗口和声音

- **收为图标**：点击右上角减号，音乐继续播放。
- **移动**：拖动卡片左上方“浮音”区域，或直接拖动音符图标。
- **缩放**：在“更多 → 设置”调整体大小，或拖动卡片右下角。范围为 90–140%，宽高和控件一起缩放。
- **透明度**：设置中的“背景不透明度”范围为 20–100%，不改变文字与按钮自身的透明度。
- **音频输出**：在设置中选择系统默认或指定设备。刚连接耳机时可点击“刷新”，然后选择对应耳机；同时检查 Windows 系统音量和浮音音量。
- **恢复外观**：设置中“重置”恢复 100% 大小及不透明度；主题可单独选择浅色、深色或跟随系统。

窗口会按屏幕可用区域限制大小和位置，内容较长时可滚动阅读。再次运行程序会唤起已有窗口。

## 退出与快捷键

“更多 → 退出浮音”停止播放并退出；图标右键菜单也提供退出。通过系统关闭窗口会退出应用，减号仅收为图标。

| 快捷键 | 操作 |
|---|---|
| Ctrl+F | 展开搜索并聚焦输入框 |
| Ctrl+O | 打开音频选择器 |
| Esc | 返回更多、收起展开区，或将卡片收为图标 |

快捷键在播放器窗口处于活动状态时使用，弹出菜单和对话框优先处理键盘输入。

## 运行与升级

解压运行包后运行 `FloatMusic.exe`，保留同目录中的 DLL 和插件。升级前退出旧版，再替换完整运行目录。歌单、收藏和设置保存在应用数据目录中；保留该目录即可延续已有数据。

没有运行包时，请参考[构建说明](DEVELOPMENT.md)。功能范围和在线服务说明见[项目主页](../README.md)。
