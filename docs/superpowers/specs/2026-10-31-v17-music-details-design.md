# 浮音 1.7：音乐资料与评论

用户于 2026-10-31 确认更新草案并要求开始制作。Windows 与 Android 同步，保留既有布局和虹彩风格；继承尚未发布的 1.6 preview.4 歌词修复。

## 已批准的范围
- 阅读歌曲热门、最新评论；作者、时间、点赞数、长评论展开，分批加载。
- 默认当前歌曲的目录来源，提供跨平台切换。资料来源独立于音频实际解析来源，不改变播放。
- 跨来源先搜索候选，由用户选择准确版本，不静默匹配翻唱、现场版。
- 展示歌曲封面、专辑、可用发行资料和评论数；展示在线歌单封面、创建者、歌曲数、来源实际提供的播放/收藏/评论数。缺失值与零区分，不把歌单播放量当作歌曲播放量。
- 保留歌单简介展开与长按复制。新增详情按需打开，不占用歌词空间。
- 资料、评论按需请求，缓存成功读取内容；网络错误可重试，离线旧数据须提示。封面缓存限额。加载不影响音频和歌词。
- 中文、英文、明暗模式、窗口缩放及手机触控。
- 不加入登录、个人收藏同步或评论写操作。

## 方案与实现判断
复用现有目录接口接入公开资料，新增独立 MusicDetails 状态模块，双端共用 C++ 请求和规范化结果，Android 经既有 JSON 桥展示。相比双端各实现请求，避免字段含义与错误状态分叉；相比网页嵌入，保持悬浮窗一致的交互。此为执行判断，沿用用户已选定的功能范围。

## 边界
各来源以实际公开接口验证为准。网易、QQ 公开评论已实测可读；酷我网页评论入口当前返回 404，必须清楚提示来源暂不可用，而非伪造空列表。热门列表无法继续翻页时不显示加载更多。

## 状态与安全
详情、评论、候选搜索均用独立请求代次；切换或关闭后迟到响应不得写入当前界面。未打开详情不请求评论。评论纯文本展示，不执行 HTML。响应长度、页数和缓存空间有限制；缓存按歌曲来源/ID/排序/页码隔离，成功响应才能覆盖缓存。

## 验收
用本地 HTTP 测试数据验证正常/空/失效/畸形响应、分页去重、迟到响应、离线缓存、平台候选确认、缺失计数。运行现有全套桌面回归；打包双端；检查实际界面的长评论、窄窗口、深浅主题。公开接口会变化，记录测试时间与可用范围。
