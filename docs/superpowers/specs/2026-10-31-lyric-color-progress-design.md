# 歌词颜色进度

用户要求：当前高亮歌词增加从左到右的颜色覆盖，并可在设置关闭；延续双端体验一致的要求。

采用现有紫色高亮覆盖可读的底色，保持字体、换行、透明度曲线、滚动、点击穿透与复制行为。播放器内与独立悬浮歌词共用一个默认开启、持久保存的“歌词颜色进度”开关，歌词设置和桌面歌词设置均提供入口。英文同步。

按当前句时间戳到下一个时间戳计算进度，最后一句使用歌曲时长；无有效时长或纯文本歌词维持原有整句高亮。现有接口只保证逐句时间戳，因此这是句内匀速覆盖，不声称逐字演唱对齐。长句换行按各行实际文字宽度依次覆盖，双语在各自文本内同步推进。暂停冻结；恢复、拖动进度、偏移、换歌立即校准。覆盖不改变文字布局。

方案比较：按字数逐字跳色简单但不连续；增加逐字歌词数据源会扩大范围且来源不稳定；选用现有时间戳与绘制裁剪，改动集中且无需新增网络请求。实现细节由开发者确定。

性能：只更新可见的当前句绘制，复用文字布局/位图，不在颜色动画中重建列表、移动系统窗口或生成位图；隐藏、关闭效果、暂停后停止帧回调。

验收：颜色从真实文字左缘覆盖到右缘，长句换行、双语、首尾句、空行间奏、暂停/恢复/定位、开关持久化、明暗主题正常，原有滚动与穿透回归通过。沿用当前工作区，保留已有未提交的 1.7 功能，不发布远端。
