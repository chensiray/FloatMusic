# 浮音 Android 1.3 视觉同步

用户已选定 07A 主视觉并授权把本次电脑端更新同步到手机；本任务复用既定设计，不重新调整布局。

## 范围与约束

- 保留 Android 1.2 的原生 OverlayWindow 结构、尺寸、字号、控制顺序、48dp 触控、缩放、嵌套滚动与播放逻辑。
- 同步桌面珠光／深色调色板，采用原生静态 Drawable 绘制角雾、光谱边缘和双玻璃线。
- 原背景透明度应用于整个材质，不应用于文字和按钮。
- 播放键使用原尺寸的紫色渐变与白色图标；输入、选中状态及弹层使用统一配色。
- 欢迎页复用 PrismaticSurface，版本升级为 1.3.0-preview / code17。
- 不发布版本、不改电脑端布局、不增加底部音乐卡片。

## 执行与验证

1. 以连接手机当前安装的 1.2 为基线，隔离偏好和样本，采集 12 个浅／深原生界面状态的真实 Bitmap 与几何树。
2. 整合原生材质、欢迎页与版本信息；在独立 ASCII 临时目录增量打包，核对签名、部署源文件与 APK 元数据。
3. 执行原有 Java 契约和 Qt 回归；以同签名覆盖安装到已连接手机，比较安装前后的真实数据校验值。
4. 用相同样本采集 1.3 的 12 个界面状态，与 1.2 比较位置、尺寸、padding、字体和触控配置；执行现有原生界面回归。
5. 人工复核实际渲染、弹层、长列表和欢迎页；交付 APK 与验收说明，保留原有用户数据与主题偏好。

实际证据集中在 `artifacts/v1.3-android-preview-2026-10-15/`，最终结果写入 `VERIFICATION.md`。
